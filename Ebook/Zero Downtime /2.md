บทที่ 2: เจ้าปลาหมึกสีส้มกับหัวใจที่เต้นผิดจังหวะ

สองชั่วโมงเต็มๆ ที่อาร์เทอร์นั่งจมอยู่กับหน้าจอคอมพิวเตอร์และสมุดโน้ตเล่มหนา

หน้าเว็บแปลภาษาถูกเปิดใช้งานอย่างหนักหน่วง จนตอนนี้ในสมุดของเขาเต็มไปด้วยภาพวาดลูกศรโยงใยไปมาด้วยลายมือหวัดๆ เพื่อสรุปสิ่งที่พี่กานต์ทิ้งโจทย์ไว้ให้เมื่อเช้า

ถ้าเทียบกับการทำงานสมัยก่อนของอาร์เทอร์ที่พอเขียนโค้ดเสร็จก็แค่ลากไฟล์ไปวางทับในเซิร์ฟเวอร์ตรงๆ ระบบของที่นี่ซับซ้อนกว่ามาก แต่มันก็เป็นระเบียบอย่างน่าทึ่ง

"โอเค... พอเห็นภาพแล้ว" อาร์เทอร์พึมพำกับตัวเอง

เขาเริ่มลงมือทำตามขั้นตอนในคู่มือ ขั้นแรกคือเข้าไปที่หน้าเว็บของ Jenkins ที่หน้าตาดูโบราณเหมือนเว็บยุคเก้าศูนย์ แต่ทำหน้าที่เป็นโรงงานผลิต อาร์เทอร์คลิกปุ่ม Build Now ของระบบจ่ายเงิน (Payment Service) ที่โคลอี้เพิ่งแก้โค้ดเสร็จ

แถบสถานะค่อยๆ วิ่งจากสีฟ้าไปจนสุด พร้อมขึ้นข้อความว่า SUCCESS

อาร์เทอร์แอบกำหมัดแน่นด้วยความดีใจไปเปราะหนึ่ง ตอนนี้โค้ดของโคลอี้ถูกแพ็กใส่กล่องที่เรียกว่า Docker Image และส่งไปเก็บไว้ในโกดังบนคลาวด์ของ AWS เรียบร้อยแล้ว

ขั้นตอนต่อไปคือพระเอกของงาน... Argo CD

อาร์เทอร์สลับหน้าจอไปที่เว็บซึ่งมีโลโก้เจ้าปลาหมึกสีส้มตัวกลม บนหน้าจอแสดงแผนผังกล่องสี่เหลี่ยมเล็กๆ โยงใยกันเหมือนรากไม้ ทุกกล่องมีสีเขียวสดใสและมีรูปหัวใจสีเขียวกำกับไว้ว่า Healthy

"พี่กานต์บอกว่า แค่กดปุ่ม Sync เจ้าปลาหมึกตัวนี้ก็จะดึงกล่องโค้ดใบใหม่ไปวางลงใน AWS EKS ที่ซิดนีย์ให้เอง..."

อาร์เทอร์สูดหายใจเข้าลึกๆ เลื่อนเมาส์ไปกดปุ่ม SYNC สีฟ้าที่มุมบนซ้าย

วงล้อสถานะเริ่มหมุนติ้วๆ จากสีเขียวเปลี่ยนเป็นสีเหลือง (Progressing) อาร์เทอร์นั่งจ้องหน้าจอตาไม่กะพริบ ลุ้นยิ่งกว่าตอนตรวจผลสลากกินแบ่งรัฐบาล ผ่านไปหนึ่งนาที... สองนาที... ระบบควรจะเปลี่ยนกลับเป็นสีเขียวได้แล้ว

แต่ทันใดนั้น รูปหัวใจสีเขียวดวงน้อยข้างๆ กล่อง payment-service ก็เปลี่ยนเป็น "รูปหัวใจแตกสลายสีแดงเถือก" พร้อมข้อความตัวหนาที่เขียนว่า Degraded!

หัวใจของอาร์เทอร์หล่นวูบไปอยู่ที่ตาตุ่ม เหงื่อเม็ดเป้งผุดขึ้นที่หน้าผากทันที

พัง... กดปุ๊บพังปั๊บเลยเหรอวะเนี่ย!

"อ้าวเฮ้ย พี่อาร์เทอร์ ทำไมหัวใจน้องปลาหมึกของพี่มันหักแบบนั้นล่ะครับนั่น"

เสียงของ ‘ภพ’ รุ่นน้องโต๊ะข้างๆ ดังขึ้นขณะชะโงกหน้ามาดูพร้อมกับดูดชานมไข่มุกในมือ อาร์เทอร์หน้าเสีย รีบหันไปหาด้วยความตื่นตระหนก

"ภพ! พี่ไม่ได้ไปแก้อะไรเลยนะ พี่แค่กด Sync ตามคู่มือเป๊ะๆ เลย แล้วอยู่ดีๆ มันก็แดงแบบนี้ ระบบที่ซิดนีย์จะล่มไหมเนี่ย!"

"ใจเย็นพี่ๆ อันนี้มันแค่ระบบทดสอบ (Staging) ลูกค้าจริงยังไม่เห็นหรอกครับ" ภพหัวเราะเบาๆ แล้วเลื่อนเก้าอี้ล้อเลื่อนไถลเข้ามาใกล้ "ไหนพี่ลองคลิกเข้าไปดูที่ตัวกล่องพอด (Pod) ที่มันแดงสิครับ ดูว่าสถานะมันฟ้องว่าอะไร"

อาร์เทอร์รีบคลิกเข้าไปตามที่ภพบอก หน้าจอแสดงข้อความภาษาอังกฤษคำหนึ่งที่ดูน่าขนลุกสำหรับมือใหม่: CrashLoopBackOff

"โอ้โห ท่าไม้ตายประจำตระกูล Kubernetes เลยครับพี่" ภพวางแก้วชานมลง "อาการนี้แปลว่า AWS EKS มันพยายามเปิดกล่องโค้ดของโคลอี้ขึ้นมาทำงานแล้ว แต่มันเปิดปุ๊บก็ดับปั๊บ แล้วก็พยายามเปิดใหม่ วนลูปตายเกิดแบบนี้ไปเรื่อยๆ ครับ"

"อ้าว แล้วทำไมมันถึงดับล่ะภพ พี่กด Jenkins ผิดขั้นตอนเหรอ?"

"ไม่ใช่ความผิดพี่หรอกครับ งาน DevOps ก็งี้แหละพี่ เวลาระบบรันไม่ขึ้น คนมักจะคิดว่าพวกเราทำพังไว้ก่อน แต่จริงๆ ต้องไปดูไส้ใน" ภพชี้ไปที่แถบเมนูคำว่า Logs บนหน้าจอ Argo CD "พี่ลองกดดู Log ตรงนี้เลยครับ มันคือบันทึกข้อความสุดท้ายก่อนที่โปรแกรมมันจะขาดใจตาย"

อาร์เทอร์คลิกไปที่แถบ Logs ทันที หน้าจอดำมืดปรากฏตัวหนังสือภาษาอังกฤษวิ่งยาวเหยียดขึ้นมาหลายสิบบรรทัด ถ้าเป็นเมื่อเช้าเขาคงตาลายและกดปิดหนีไปแล้ว แต่ด้วยสัญชาตญาณของคนที่เคยเป็นโปรแกรมเมอร์มาก่อน สายตาของเขาจึงกวาดหาคำว่า Error หรือ Exception อย่างรวดเร็ว

และเขาก็เจอมันอยู่ที่บรรทัดล่างสุด!

Error: Missing required environment variable 'SYDNEY_TAX_RATE_V2'. Application cannot start.

อาร์เทอร์ขมวดคิ้ว แม้ภาษาอังกฤษของเขาจะไม่แข็งแรง แต่คำศัพท์พื้นฐานแค่นี้เขาแปลออก

"มันบอกว่า... หาตัวแปรที่ชื่อว่า SYDNEY_TAX_RATE_V2 ไม่เจอ โปรแกรมเลยเริ่มทำงานไม่ได้" อาร์เทอร์หันไปบอกภพ

"โป๊ะเชะเลยพี่!" ภพดีดนิ้วดังเปาะ "โคลอี้แอบเพิ่มตัวแปรใหม่ในโค้ดตัวเอง แต่ลืมมาเพิ่มชื่อตัวแปรนี้ในไฟล์ตั้งค่า Deployment ของฝั่งเรา พอเอาขึ้นระบบจริงมันก็เลยหาไม่เจอไงครับ... แบบนี้พี่อาร์เทอร์ต้องทัก Slack ไปบอกโคลอี้แล้วล่ะ"

คำว่า "ทักไปบอกโคลอี้" ทำเอาความดีใจที่หาสาเหตุเจอเมื่อครู่หายวับไปทันที

ต้องพิมพ์ภาษาอังกฤษคุยกับฝรั่ง... แถมเป็นการทักไปบอกว่างานของอีกฝ่ายมีปัญหาด้วย!

"ภพ... ภพช่วยพิมพ์บอกโคลอี้ให้พี่หน่อยได้ไหม พี่กลัวพิมพ์ผิดไวยากรณ์ เดี๋ยวเขาอ่านไม่รู้เรื่อง" อาร์เทอร์พูดเสียงอ่อย ความไม่มั่นใจในตัวเองกลับมาเกาะกุมจิตใจอีกครั้ง

จังหวะนั้นเอง ‘พี่กานต์’ ที่เพิ่งเดินกลับมาจากห้องน้ำก็วางมือลงบนพนักเก้าอี้ของอาร์เทอร์พอดี

"ให้ภพพิมพ์ให้วันนี้ แล้ววันพรุ่งนี้จะให้ใครพิมพ์ให้อีกล่ะอาร์เทอร์?" พี่กานต์พูดด้วยน้ำเสียงเรียบๆ แต่แฝงความหวังดี "เชื่อพี่ คนทำงานสายเทคนิคต่างชาติ เขาไม่มานั่งจับผิดแกรมม่าเราหรอก ขอแค่สื่อสารให้ตรงประเด็น มีหลักฐานคือ Log บรรทัดนั้นแปะไปให้เขาดู ลองพิมพ์เองดูก่อน เดี๋ยวพี่ช่วยตรวจให้ก่อนกดส่ง"

อาร์เทอร์เม้มปากแน่น มองหน้าพี่กานต์สลับกับรูปถ่ายของลูกชายใต้จอมอนิเตอร์

จริงของพี่กานต์... ถ้าเรื่องแค่นี้เขายังต้องหลบหลังรุ่นน้องที่อายุน้อยกว่าตั้งสี่ปี แล้วเขาจะเติบโตในบริษัทนี้ได้ยังไง

อาร์เทอร์หันกลับไปที่หน้าจอ เปิดโปรแกรมแชท Slack ขึ้นมา ค้นหาชื่อ Chloe (ANZ-Dev) แล้วเริ่มพิมพ์ข้อความภาษาอังกฤษลงในโปรแกรมแปลภาษาก่อนจะนำมาเรียบเรียงใหม่ด้วยตัวเอง เขาแก้แล้วลบอยู่เกือบห้านาที จนได้ข้อความสั้นๆ สองประโยค:

Hi Chloe, I deployed payment-service on Staging, but the pod is CrashLoopBackOff.
I checked the logs and found this error: Missing required environment variable 'SYDNEY_TAX_RATE_V2'. Could you please check?

"ประมาณนี้... พอไหวไหมครับพี่กานต์?" อาร์เทอร์ถามอย่างไม่มั่นใจ

พี่กานต์ก้มลงอ่าน แล้วตบไหล่เขาดังปุๆ "ชัดเจน ตรงประเด็น ฝรั่งอ่านปุ๊บเข้าใจปั๊บ กดส่งเลย!"

อาร์เทอร์กลั้นใจกดปุ่ม Enter ส่งข้อความนั้นออกไป หัวใจเต้นตุ้มๆ ต่อมๆ รอดูปฏิกิริยาจากปลายทางที่ซิดนีย์ซึ่งตอนนี้เป็นเวลาบ่ายสองโมงกว่าแล้ว

ไม่ถึงหนึ่งนาที จุดสีเขียวข้างชื่อของโคลอี้ก็กะพริบ พร้อมข้อความตอบกลับเด้งขึ้นมา:

Chloe: Oh mate! My bad! 😱 I totally forgot to update the deployment YAML file with the new variable. Give me 2 mins, I'll push the fix right now. Good catch, Arthur! Thanks heaps!

พร้อมกับอิโมจิรูปยกนิ้วโป้ง 👍 ต่อท้ายข้อความของอาร์เทอร์

อาร์เทอร์จ้องมองคำว่า "Good catch, Arthur! Thanks heaps!" บนหน้าจอ แม้คำว่า Thanks heaps จะเป็นคำแสลงออสซี่ที่เขาต้องแอบเอาไปค้นกูเกิลดูว่าแปลว่า ขอบคุณมากๆ แต่ความรู้สึกตื้นตันบางอย่างก็เอ่อล้นขึ้นมาในอก

เขาทำได้... เขาหาสาเหตุที่ระบบพังเจอด้วยตัวเอง และสื่อสารกับเพื่อนร่วมงานต่างชาติรู้เรื่องโดยที่ไม่มีใครหัวเราะเยาะภาษาอังกฤษของเขาเลยสักนิด!

ห้านาทีต่อมา โคลอี้ก็ส่งไฟล์แก้ไขเข้ามา อาร์เทอร์กด Sync ใน Argo CD อีกครั้ง และคราวนี้... กล่องสี่เหลี่ยมทุกกล่องค่อยๆ เปลี่ยนเป็นสีเขียวสดใส พร้อมรูปหัวใจดวงน้อยที่กลับมาเต้นเป็นจังหวะปกติ (Healthy)

17:30 น.

"พี่กานต์ ภพ ผมกลับก่อนนะครับ สวัสดีครับ"

อาร์เทอร์สะพายกระเป๋าเป้เดินออกจากออฟฟิศตรงเวลาเป๊ะเป็นวันแรก ในหัวของเขายังคงมีคำศัพท์ใหม่อย่าง Pod, Deployment, และ CrashLoopBackOff วิ่งวนอยู่เต็มไปหมด แต่มันไม่ได้สร้างความหวาดกลัวให้เขาเหมือนเมื่อเช้าอีกแล้ว

ระหว่างยืนรอรถไฟฟ้า อาร์เทอร์หยิบสมาร์ทโฟนขึ้นมา เปิดแอปพลิเคชันฝึกฟังภาษาอังกฤษที่เขาเพิ่งดาวน์โหลดมาเมื่อตอนพักเที่ยง แล้วเสียบหูฟังใส่หู

ก้าวแรกในวัยสามสิบมันอาจจะช้าและทุลักทุเลไปหน่อย... แต่ตราบใดที่เขายังไม่หยุดเดิน วันพรุ่งนี้เขาจะต้องเก่งขึ้นกว่าวันนี้แน่นอน!
