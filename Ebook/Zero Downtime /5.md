บทที่ 5: เสียงไซเรนสีแดงและศึกหนักวันศุกร์

คนในวงการไอทีมีกฎเหล็กที่รู้กันดีแต่ไม่เคยมีใครเขียนแปะไว้ข้างฝาอยู่ข้อหนึ่ง นั่นคือ... "ห้ามเอาโค้ดสำคัญขึ้นระบบจริงในวันศุกร์ (Never Deploy on Friday)"

แต่สำหรับบริษัทระดับโลกที่กำลังแข่งขันอย่างดุเดือด กฎข้อนี้มักถูกฉีกทิ้งเสมอ

วันศุกร์ เวลา 10:30 น. (ตรงกับเวลาบ่ายสองโมงครึ่งของซิดนีย์)

อาร์เทอร์เพิ่งเชื่อมต่อระบบระหว่าง GitHub Actions กับเจ้าปลาหมึกสีส้ม Argo CD ของระบบจ่ายเงินเสร็จสมบูรณ์เมื่อสิบนาทีที่แล้ว ตอนนี้ทุกครั้งที่โคลอี้แก้โค้ด ระบบจะทำการสร้างกล่องอิมเมจใหม่ เปลี่ยนเลขเวอร์ชันในไฟล์ตั้งค่า และสั่งให้ Argo CD อัปเดตระบบบน AWS EKS ที่ซิดนีย์โดยอัตโนมัติภายในเวลาไม่ถึงสามนาที

มันคือความสำเร็จชิ้นแรกที่ทำให้อาร์เทอร์ภูมิใจจนแทบจะยิ้มแก้มปริ... ถ้าไม่ใช่เพราะเสียงแจ้งเตือนภัยพิบัติที่จู่ๆ ก็แผดร้องขึ้นมา!

ตือดึง! ตือดึง! ตือดึง!

เสียงแจ้งเตือนจากแอปพลิเคชัน PagerDuty ดังประสานเสียงกันจากโทรศัพท์มือถือของทุกคนในทีม Blue พร้อมกับหน้าจอมอนิเตอร์ขนาดใหญ่กลางห้องที่แสดงกราฟสถานะของเซิร์ฟเวอร์ฝั่งออสเตรเลีย ค่อยๆ เปลี่ยนจากสีเขียวเป็น สีแดงฉาน ทีละจุด!

"เฮ้ย! ระบบจ่ายเงินของซิดนีย์ (Production) ร่วง!" ภพร้องเสียงหลง มือที่ถือแก้วชานมไข่มุกชะงักค้าง

หัวใจของอาร์เทอร์กระตุกวูบ ความเย็นเฉียบแล่นปราดจากปลายเท้าขึ้นมาถึงขมับ... ระบบจ่ายเงิน? ระบบที่เขาเพิ่งผูก GitHub Actions เสร็จเมื่อกี้เนี่ยนะ?!

ยังไม่ทันที่อาร์เทอร์จะได้ตั้งสติ หน้าต่างโปรแกรมประชุมออนไลน์ฉุกเฉินที่เรียกว่า ‘War Room’ (ห้องบัญชาการรบ) ก็เด้งขึ้นมาบนหน้าจอของทุกคนโดยอัตโนมัติ

ทันทีที่กดรับสาย เสียงภาษาอังกฤษที่เต็มไปด้วยความตึงเครียดของ ‘เลียม’ และ ‘โคลอี้’ ก็ดังทะลุหูฟังเข้ามาทันที

"Blue Team! We have a P1 Incident!" เสียงของเลียมเข้มจัด ไม่มีคำว่า G'day mate อย่างเคย "The Flash Sale campaign in Sydney just started five minutes ago, and our payment service is throwing 503 Service Unavailable! Customers can't checkout!"(ทีม Blue! เราเจอวิกฤตระดับ 1! แคมเปญลดราคาที่ซิดนีย์เพิ่งเริ่มเมื่อห้านาทีที่แล้ว แต่ระบบจ่ายเงินของเราขึ้น Error 503! ลูกค้าจ่ายเงินไม่ได้!)

"Wait, did Arthur's new GitHub Actions pipeline just deploy something to Production?!" เสียงของโคลอี้แทรกขึ้นมาด้วยความตกใจ

ชื่อของตัวเองที่ถูกเอ่ยออกมาท่ามกลางวิกฤตที่บริษัทกำลังสูญเสียรายได้วินาทีละหลายแสนบาท ทำเอาอาร์เทอร์หน้าซีดเผือด มือที่วางอยู่บนคีย์บอร์ดสั่นเทา

เพราะเราเหรอ... เราทำระบบใหญ่ของออสเตรเลียพังเหรอ?! ถ้าโดนไล่ออกตอนนี้ แล้วออกัสกับแพรจะทำยังไง!

"ตั้งสติอาร์เทอร์!"

เสียงเข้มๆ ของ ‘พี่กานต์’ ตบลงที่ไหล่ของอาร์เทอร์อย่างแรงจนเขาสะดุ้ง

"อย่าเพิ่งลน! เมื่อกี้พี่ตรวจโค้ดของอาร์เทอร์ก่อนเอาขึ้นแล้ว Pipeline ของเราไม่ได้ทำอะไรผิด! เปิดหน้าจอ AWS EKS กับ Argo CD ขึ้นมาเดี๋ยวนี้ ดูว่ามันเกิดอะไรขึ้นกับพอด (Pod) ที่ซิดนีย์!"

คำพูดหนักแน่นของหัวหน้าทีมฝั่งไทยช่วยดึงวิญญาณของอาร์เทอร์กลับเข้าร่าง เขาสูดหายใจลึก ข่มความกลัวไว้ข้างหลัง แล้วรัวคำสั่งเปิดดูสถานะของกล่องคอนเทนเนอร์บน AWS EKS ทันที

ในขณะที่ ‘ราจ’ หนุ่มอินเดียกำลังรัวภาษาอังกฤษรายงานเลียมว่าฐานข้อมูลยังปกติดี และ ‘ภพ’ กำลังเช็กกราฟทราฟฟิก อาร์เทอร์ก็จ้องมองไปที่หน้าจอ Argo CD ตาไม่กะพริบ

กล่องพอดของ payment-service ทั้ง 3 กล่อง ไม่ได้พังตอนเริ่มรันเหมือนวันแรก... แต่มันกำลังขึ้นสถานะสีแดงตัวโตๆ ว่า:

OOMKilled (Out Of Memory Killed)

พอดตัวที่หนึ่งดับไป... Argo CD พยายามสร้างตัวใหม่ขึ้นมาแทน แต่พอสร้างเสร็จได้แค่สิบวินาที มันก็ขึ้น OOMKilled แล้วดับไปอีก!

"พี่กานต์ครับ!" อาร์เทอร์ร้องบอกเสียงดัง "พอดมันไม่ได้พังเพราะโค้ดอัปเดตครับ แต่มันขึ้นว่า OOMKilled... เมมโมรี่มันเต็มจนระบบสั่งฆ่าพอดทิ้งรัวๆ เลยครับ!"

พี่กานต์ชะโงกหน้ามาดูแวบเดียวก่อนจะสบถออกมาเบาๆ "ชัดเลย! คนเข้ามาซื้อของในแคมเปญ Flash Sale เยอะกว่าปกติห้าเท่า แต่พอดของเรามีแค่ 3 ตัว แถมจำกัดเมมโมรี่ไว้แค่นิดเดียว มันเลยรับคนไม่ไหวแล้วระเบิดตายต่อหน้าต่อตา!"

"Karn! What's the status?! Do we need to rollback?!" เสียงของเลียมตะโกนถามมาจากเมลเบิร์น เพราะตอนนี้เวลาผ่านไปสามนาทีแล้ว และกราฟยอดขายของบริษัทกำลังดิ่งลงเหว

พี่กานต์กำลังจะกดเปิดไมค์ตอบ แต่นิ้วของเขากลับต้องพิมพ์คำสั่งช่วยภพรับมือกับระบบหน้าบ้านที่กำลังจะล่มตามไปด้วย พี่กานต์จึงหันมามองอาร์เทอร์ด้วยสายตาจริงจัง

"อาร์เทอร์! พี่มือไม่ว่าง... เปิดไมค์บอกเลียมเดี๋ยวนี้ว่า 'ไม่ต้อง Rollback! ปัญหาคือ Memory Limit ไม่พอ และเราต้องเพิ่มจำนวนพอด!' พูดออกไปเลย!"

"ผะ... ผมเหรอครับ?!"

ในห้องประชุมออนไลน์ตอนนี้มีทั้งเลียม โคลอี้ ราจ และผู้บริหารฝั่งออสเตรเลียอีกสองคนที่เพิ่งเข้ามาฟังสถานการณ์ การต้องพูดภาษาอังกฤษท่ามกลางวิกฤตระดับนี้คือฝันร้ายที่สุดในชีวิตของอาร์เทอร์

แต่เมื่อเขาเห็นพี่กานต์กับภพกำลังหัวหมุนช่วยกันพยุงระบบอย่างสุดกำลัง อาร์เทอร์ก็กัดฟันแน่น

ไม่มีเวลามากลัวพูดผิดแกรมม่าแล้วโว้ย!

อาร์เทอร์กดปุ่มเปิดไมค์ สูดลมหายใจเข้าปอด แล้วตะโกนประโยคภาษาอังกฤษที่ตัดคำฟุ่มเฟือยออกทั้งหมด เน้นเฉพาะคีย์เวิร์ดสำคัญออกไปทันที!

"Liam! No rollback! Your code is fine!"

เสียงของอาร์เทอร์ดังฟังชัดจนทั้งห้องประชุมเงียบกริบ

"The problem is... High traffic! Pods are OOMKilled! Memory is full! I will... increase memory and scale pods in Argo CD right now!"(เลียม! ไม่ต้องถอยโค้ดกลับ! โค้ดของคุณปกติ! ปัญหาคือคนเข้าเยอะเกินไป พอดตายเพราะเมมโมรี่เต็ม! ผมจะเพิ่มเมมโมรี่และขยายจำนวนพอดใน Argo CD เดี๋ยวนี้ครับ!)

ปลายสายที่ออสเตรเลียเงียบไปหนึ่งวินาที ก่อนที่เสียงของเลียมจะตอบกลับมาอย่างรวดเร็วและเด็ดขาด

"Understood, Arthur! Good diagnostic! You have my permission. Scale it up to 10 pods and double the memory limit. Use your new GitHub Actions pipeline to push the change NOW!"(เข้าใจแล้วอาร์เทอร์! วิเคราะห์ได้เยี่ยมมาก! ผมอนุญาต ขยายเป็น 10 พอดและเพิ่มเมมโมรี่เป็นสองเท่าเลย ใช้ระบบ GitHub Actions ตัวใหม่ของคุณส่งค่าขึ้นไปเดี๋ยวนี้!)

"Yes, sir!"

อาร์เทอร์รับคำสั้นๆ วินาทีนี้สมองของเขาทำงานเร็วกว่าตอนเขียนโปรแกรมสมัยก่อนถึงสิบเท่า เขาสลับหน้าจอไปที่ไฟล์ตั้งค่า deployment.yaml ของระบบจ่ายเงิน

นิ้วของเขาพิมพ์แก้ตัวเลขอย่างแม่นยำโดยไม่เคาะวรรคผิดแม้แต่ช่องเดียว:

แก้จำนวนพอด (replicas) จาก 3 เป็น 10

แก้ขนาดหน่วยความจำ (memory limits) จาก 512Mi เป็น 1024Mi

อาร์เทอร์พิมพ์คำสั่ง git commit และ git push ส่งไฟล์ที่แก้เสร็จขึ้นไปบน GitHub ทันที!

"ผมส่งโค้ดแก้ขึ้นไปแล้วครับพี่กานต์!" อาร์เทอร์บอกเสียงสั่นด้วยความตื่นเต้น

"เยี่ยม! ทีนี้แหละ เราจะได้รู้กันว่าไอ้ระบบอัตโนมัติที่เราอดหลับอดนอนทำมาสองวัน มันจะช่วยชีวิตพวกเราได้จริงไหม!" พี่กานต์จ้องหน้าจอเขม็ง

ถ้าเป็นเมื่อก่อนที่ยังใช้คุณปู่ Jenkins พวกเขาต้องรอคิวอย่างน้อย 10 นาทีกว่าระบบจะอัปเดตเสร็จ ซึ่งป่านนั้นลูกค้าชาวออสเตรเลียคงหนีหายไปหมดแล้ว

แต่ด้วย GitHub Actions ที่อาร์เทอร์เพิ่งสร้างเสร็จ... ทันทีที่เขากดส่งโค้ด ไม่ถึง 15 วินาที มันก็ตรวจสอบสิทธิ์ผ่าน OIDC และส่งคำสั่งต่อไปยัง Argo CD ทันที!

บนหน้าจอของทุกคนในทีม Blue เจ้าปลาหมึกสีส้มเริ่มขยับหนวดทำงานอย่างบ้าคลั่ง กล่องสี่เหลี่ยมของพอดใน AWS EKS ที่ซิดนีย์ ถูกเสกเพิ่มขึ้นมาเรียงรายกัน 10 กล่องรวดภายในพริบตา!

จากสีเหลือง... ค่อยๆ เปลี่ยนเป็น สีเขียว (Healthy) หนึ่งกล่อง... สองกล่อง... ห้ากล่อง... จนกระทั่งครบทั้ง 10 กล่อง!

ทราฟฟิกมหาศาลจากลูกค้าในซิดนีย์ถูกกระจายเข้าไปยังพอดทั้ง 10 ตัวที่ตอนนี้มีเมมโมรี่กว้างขวางอย่างนุ่มนวล กราฟสีแดงเถือกบนจอมอนิเตอร์กลางห้องค่อยๆ ลดระดับลง... จนกลายเป็นเส้นสีเขียวที่ราบเรียบและสวยงามในที่สุด!

ตือดึง!

เสียงแจ้งเตือนจากระบบดังขึ้นอีกครั้ง แต่คราวนี้เป็นข้อความสีเขียวที่เขียนว่า: RESOLVED: Payment Service is back to normal. (แก้ไขสำเร็จ: ระบบจ่ายเงินกลับสู่สภาวะปกติ)

"Bloody brilliant, Blue Team!!"

เสียงร้องตะโกนด้วยความสะใจของเลียมดังลั่นมาจากลำโพง พร้อมกับเสียงปรบมือรัวๆ ของโคลอี้และทีมงานฝั่งออสเตรเลีย

"Checkout rate is back to 100%! Arthur, your new GitHub Actions pipeline just saved our Friday! It deployed the fix in less than a minute! Legend, mate! Absolute legend!"(อัตราการจ่ายเงินกลับมา 100% แล้ว! อาร์เทอร์ ระบบ GitHub Actions ใหม่ของคุณเพิ่งช่วยชีวิตวันศุกร์ของพวกเราไว้! มันอัปเดตระบบเสร็จในเวลาไม่ถึงนาที! นายคือตำนานเพื่อนยาก! ตำนานตัวจริงเลย!)

อาร์เทอร์ทิ้งมือทั้งสองข้างลงข้างลำตัว ถอนหายใจยาวเหยียดจนสุดปอด แผ่นหลังของเขาชุ่มไปด้วยเหงื่อ แต่หัวใจที่เต้นรัวอยู่ในอกกลับพองโตอย่างที่ไม่เคยเป็นมาก่อนในชีวิตการทำงานตลอดแปดปี

คำว่า "Legend (ตำนาน)" จากปากของหัวหน้าชาวต่างชาติที่เขาเคยกลัวจนตัวสั่นเมื่อวันจันทร์... วันนี้เขากลับได้รับมันมาด้วยฝีมือของตัวเอง!

"สุดยอดเลยพี่อาร์เทอร์! เปิดไมค์สั่งการเป็นภาษาอังกฤษอย่างเท่ แถมกู้เซิร์ฟเวอร์ซิดนีย์ได้ในหนึ่งนาที!" ภพหันมากอดคอเขย่าตัวรุ่นพี่ด้วยความดีใจ ขณะที่ราจก็ยกนิ้วโป้งทั้งสองข้างส่งมาให้จากโต๊ะข้างๆ

พี่กานต์ตบไหล่อาร์เทอร์เบาๆ ด้วยรอยยิ้มกว้าง "เห็นไหม พี่บอกแล้วว่าคนเราไม่ได้วัดกันที่ว่าจบจากมหาลัยไหน หรืออายุเท่าไหร่... แต่วัดกันที่ว่าตอนหน้าสิ่วหน้าขวาน เราทำอะไรได้บ้างต่างหาก วันนี้นายสอบผ่านการเป็น DevOps เต็มตัวแล้วนะอาร์เทอร์"

"ขอบคุณครับพี่กานต์... ถ้าไม่ได้พี่กับภพคอยสอน ผมคงทำไม่ได้หรอกครับ" อาร์เทอร์ยิ้มรับด้วยความตื้นตัน

เขาหยิบโทรศัพท์มือถือขึ้นมาดู เห็นข้อความไลน์จาก ‘แพร’ ที่ส่งรูปของ ‘น้องออกัส’ กำลังถือใบงานวาดรูปครอบครัวที่ได้ดาวสีทองสามดวงจากคุณครูมาอวด พร้อมข้อความว่า ‘เย็นนี้ปะป๊าอยากกินอะไรเป็นพิเศษไหมคะ?’

อาร์เทอร์คลี่ยิ้มอบอุ่น พิมพ์ตอบภรรยากลับไปว่าขอเป็นหมูกระทะฉลองวันศุกร์

สัปดาห์แรกในโลกใบใหม่ของคุณพ่อวัยสามสิบผ่านพ้นไปแล้ว แม้หนทางข้างหน้ายังมีบอสตัวใหญ่อีกหลายตัวในโลกของ Cloud รอให้เขาไปปราบ... แต่วันนี้ อาร์เทอร์รู้แล้วว่าเขาไม่จำเป็นต้องกลัวมันอีกต่อไป!
