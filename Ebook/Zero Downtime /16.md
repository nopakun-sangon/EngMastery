
บทที่ 16: พายุที่กำลังก่อตัว และมนตราเสกตึกของ Terraform

เช้าวันพุธ พี่กานต์เดินเข้ามาในออฟฟิศพร้อมกับกระเป๋าเดินทางใบย่อม

"อาร์เทอร์ ภพ ราจ... อย่างที่รู้กันว่าบ่ายนี้พี่ต้องบินไปประชุมวางแผนงานปีหน้าที่เมลเบิร์นกับเลียมเป็นเวลาหนึ่งสัปดาห์เต็ม" พี่กานต์พูดพลางตบไหล่อาร์เทอร์ที่ตอนนี้มีป้ายดิจิทัล CKA ประดับอยู่ในโปรไฟล์บริษัทเรียบร้อยแล้ว

"และในวันศุกร์ที่จะถึงนี้ คือเทศกาล Black Friday ของออสเตรเลีย... แคมเปญช้อปปิ้งที่ใหญ่ที่สุดในรอบปี ที่ทราฟฟิกจะไม่ได้มาแค่ 5 เท่าเหมือนตอน Flash Sale แต่จะพุ่งสูงถึง 15 เท่า จากปกติ! ระหว่างที่พี่อยู่บนเครื่องบินและติดประชุมที่นู่น อาร์เทอร์จะต้องรับหน้าที่เป็น Acting Lead (รักษาการหัวหน้าทีม Blue) ดูแลการเตรียมความพร้อมทั้งหมดที่นี่!"

คำว่า รักษาการหัวหน้าทีม ทำให้อาร์เทอร์ยืดตัวตรงด้วยความมุ่งมั่น "ไว้ใจได้เลยครับพี่กานต์ ผมกับภพและพี่ราจจะดูแลทางนี้ให้ดีที่สุดครับ"

"ดีมาก... และงานแรกของการเตรียมรับพายุ Black Friday คือ เราต้องขยายขนาดคลัสเตอร์ AWS EKS และสร้างระบบแคชข้อมูลความเร็วสูง (AWS ElastiCache Redis) เพิ่มขึ้นมาอีกชุดหนึ่งเพื่อช่วยแบ่งเบาภาระฐานข้อมูลของราจ"

พี่กานต์ชี้ไปที่หน้าจอ "แต่ห้ามใครเข้าไปกดสร้างเซิร์ฟเวอร์ด้วยมือในหน้าเว็บ AWS Console เด็ดขาดนะ! เพราะถ้ากดสร้างด้วยมือ วันไหนจบแคมเปญแล้วอยากลบออก เราจะลืมว่าเราไปกดตั้งค่าอะไรไว้ตรงไหนบ้าง... เราต้องใช้เครื่องมือชิ้นสุดท้ายที่จะทำให้อาร์เทอร์กลายเป็น DevOps ที่สมบูรณ์แบบ นั่นคือ Terraform (Infrastructure as Code)!"

อาร์เทอร์เคยเห็นเอเลน่ากับราจพูดถึงคำว่า Terraform มาบ้างแล้ว มันคือเครื่องมือที่มีโลโก้เป็นรูปตัว T สีม่วง

"ถ้า Helm กับ Argo CD คือการเขียนโค้ดเพื่อสั่งเสก 'พอด (คนเช่าตึก)'... เจ้า Terraform ก็คือการเขียนโค้ดเพื่อสั่งเสก 'ตัวตึกเซิร์ฟเวอร์, ถนน VPC, และฐานข้อมูลบน AWS' ทั้งหมดขึ้นมาจากความว่างเปล่า!" ราจช่วยอธิบายเสริมด้วยภาษาอังกฤษที่ตอนนี้อาร์เทอร์ฟังเข้าใจได้เกือบ 90% แล้วโดยไม่ต้องให้ใครแปล

หลังจากพี่กานต์เดินทางไปสนามบิน อาร์เทอร์ในฐานะรักษาการหัวหน้าทีมก็นั่งลงศึกษาไฟล์โค้ดของ Terraform (.tf) ร่วมกับราจและภพทันที

หลักการทำงานของ Terraform นั้นมี 2 คำสั่งศักดิ์สิทธิ์ที่ต้องจำให้ขึ้นใจ:

terraform plan (ดูพิมพ์เขียวก่อนสร้างจริง): สั่งให้ระบบคำนวณดูว่า ถ้าเราแก้โค้ดแบบนี้ มันจะไป สร้างเพิ่ม (+ สีเขียว), แก้ไข (~ สีเหลือง), หรือ ทุบทิ้ง (- สีแดง) ตึกหลังไหนบน AWS บ้าง

terraform apply (ลงมือตอกเสาเข็มจริง): สั่งให้สร้างหรือทุบตามพิมพ์เขียวที่ได้ตรวจดูแล้ว

"เดี๋ยวผมช่วยแก้โค้ดเพิ่มจำนวนเครื่องเซิร์ฟเวอร์ของ EKS จาก 5 เครื่องเป็น 20 เครื่องให้เองครับพี่อาร์เทอร์!" ภพอาสาด้วยความกระตือรือร้น

ภพเข้าไปแก้ไฟล์โค้ด Terraform ของคลัสเตอร์ซิดนีย์เพื่อเพิ่มจำนวนเครื่อง พร้อมกับแอบแก้ชื่อกลุ่มเซิร์ฟเวอร์ (Node Group Name) จากชื่อเก่า syd-prod-nodes ให้เป็นชื่อใหม่ที่ดูเท่กว่าเดิมคือ syd-blackfriday-nodes โดยไม่ได้คิดอะไร

จากนั้นภพก็ส่งโค้ดขึ้นไปใน GitHub เพื่อให้ระบบรันคำสั่ง terraform plan ออกมาเตรียมให้กดยืนยัน

"พี่อาร์เทอร์ครับ ผมส่งโค้ดขึ้นไปแล้ว พี่ช่วยกด Approve (อนุมัติ) ให้มันรัน terraform apply หน่อยครับ จะได้เสร็จก่อนเลิกงาน!" ภพหันมาบอก

อาร์เทอร์กำลังจะเลื่อนเมาส์ไปกดปุ่มอนุมัติตามที่รุ่นน้องบอก... แต่สัญชาตญาณของคนที่ผ่านสนามสอบและวิกฤตมานับครั้งไม่ถ้วน กระซิบเตือนเขาว่า: ‘เป็นหัวหน้าทีม ต้องตรวจพิมพ์เขียว (plan) ทุกบรรทัดด้วยตาตัวเองก่อนกดอนุมัติเสมอ!’

อาร์เทอร์คลิกเปิดดูผลลัพธ์ของ terraform plan ที่ยาวเหยียดกว่าสองร้อยบรรทัด เขาเลื่อนลงมาดูบรรทัดสรุปสุดท้าย... แล้วเลือดในกายของอาร์เทอร์ก็เย็นเฉียบไปทั้งร่าง!

Plan: 20 to add, 0 to change, 5 to destroy.
# aws_eks_node_group.main must be replaced (-/+ destroy and then create replacement)

มีเครื่องหมายลบสีแดง 5 to destroy (สั่งทุบทิ้ง 5 เครื่อง) โผล่ขึ้นมาหรา!

"ภพ!! หยุดเดี๋ยวนี้! ห้ามกด Apply เด็ดขาด!!" อาร์เทอร์ร้องเสียงหลง รีบกดปุ่ม Reject (ปฏิเสธคำขอ) ใน GitHub ทันที!

"อ้าว ทำไมล่ะครับพี่อาร์เทอร์? ผมแค่เพิ่มจำนวนเครื่องกับเปลี่ยนชื่อกลุ่มเซิร์ฟเวอร์ให้มันสื่อถึงงาน Black Friday เองนะครับ?" ภพถามหน้าเหรอหรา

ราจที่รีบชะโงกหน้ามาดูผล plan ถึงกับหน้าซีดเผือด ยกมือทึ้งหัวตัวเอง "Oh my goodness! Phop! In Terraform, changing the node_group_name forces a Replacement (Destroy and Recreate)! If Arthur had clicked approve, Terraform would have destroyed all 5 existing Production servers in Sydney right now before creating the new ones!"(คุณพระช่วย! ภพ! ใน Terraform การเปลี่ยนชื่อกลุ่มโหนดจะบังคับให้ระบบทำการ 'ทุบทิ้งแล้วสร้างใหม่'! ถ้าเมื่อกี้อาร์เทอร์เผลอกดอนุมัติไป Terraform จะทำการระเบิดเครื่องเซิร์ฟเวอร์ Production ทั้ง 5 เครื่องที่ซิดนีย์ทิ้งทันทีก่อนที่จะสร้างเครื่องใหม่ขึ้นมา!)

ภพหน้าซีดเป็นกระดาษ A4 เหงื่อแตกพลั่กออกเต็มหน้าผาก "ทะ... ทุบทิ้งทั้ง 5 เครื่องที่กำลังรันงานจริงอยู่ตอนนี้เลยเหรอครับ?! แค่เปลี่ยนชื่อบรรทัดเดียวเนี่ยนะ?!"

"ใช่แล้วภพ!" อาร์เทอร์ถอนหายใจเฮือกใหญ่ หัวใจยังเต้นรัวไม่หาย "ในโลกของ Infrastructure as Code การเปลี่ยนชื่อทรัพยากรหลัก มันไม่ได้แปลว่าการเอายางลบไปลบป้ายชื่อแล้วเขียนใหม่... แต่มันแปลว่าการสั่งรถแบ็กโฮมาทุบตึกเก่าทิ้งทั้งหลัง แล้วค่อยสร้างตึกใหม่ที่มีชื่อใหม่ขึ้นมาแทน! ถ้าพี่กดอนุมัติไปเมื่อกี้ แอปทั้งหมดของออสเตรเลียจะดับมืดไปอย่างน้อยสิบห้านาทีเลยนะ!"

"ผม... ผมขอโทษครับพี่อาร์เทอร์! ผมไม่รู้จริงๆ ว่าการเปลี่ยนชื่อใน Terraform มันร้ายแรงขนาดนี้ ขอบคุณพี่มากนะครับที่อ่าน plan อย่างละเอียดก่อน!" ภพยกมือไหว้รุ่นพี่ด้วยมือที่สั่นเทา รู้สึกเหมือนตัวเองเพิ่งรอดตายจากการทำบริษัทสูญเงินร้อยล้านมาได้อย่างหวุดหวิด

อาร์เทอร์ตบไหล่ภพเบาๆ เพื่อเรียกสติรุ่นน้อง "จำไว้เป็นบทเรียนนะภพ เวลาใช้ Terraform ห้ามดูแค่ตัวเลขสีเขียว (+ add) อย่างเดียว ต้องดูตัวเลขสีแดง (- destroy) เสมอ ถ้าเห็นคำว่า must be replaced หรือมีตัวเลขสั่งทุบทิ้งแม้แต่เลข 1 บน Production... ต้องหยุดมือทันที!"

อาร์เทอร์จัดการแก้โค้ดของภพให้ใช้ชื่อกลุ่มเซิร์ฟเวอร์ชื่อเดิม เปลี่ยนแค่ตัวเลขจำนวนเครื่อง และเขียนโค้ดสร้างตึกใหม่แยกต่างหากขึ้นมาอีกชุดแทน คราวนี้เมื่อรัน terraform plan ผลลัพธ์ที่ได้คือ:

Plan: 15 to add, 1 to change, 0 to destroy.

ศูนย์การทุบทิ้ง (0 to destroy)!

อาร์เทอร์กดปุ่มอนุมัติให้ Terraform ทำงาน เครื่องเซิร์ฟเวอร์ใหม่ 15 เครื่องพร้อมระบบแคชข้อมูล Redis ถูกเสกขึ้นมาบนคลาวด์ AWS ที่ซิดนีย์อย่างปลอดภัยและไร้รอยต่อ เตรียมพร้อมเป็นป้อมปราการเหล็กสำหรับศึกใหญ่ในวันศุกร์นี้เรียบร้อยแล้ว!

ค่ำวันนั้น พี่กานต์ที่เพิ่งลงจากเครื่องบินที่เมลเบิร์น ได้เข้ามาเห็นประวัติการตรวจโค้ดใน GitHub และเห็นว่าอาร์เทอร์เพิ่งช่วยหยุดยั้งหายนะจากการสั่งทุบเซิร์ฟเวอร์ด้วย Terraform เอาไว้ได้ทันเวลา

ข้อความสั้นๆ จากพี่เลี้ยงถูกส่งมาหาอาร์เทอร์ทางไลน์ส่วนตัว:

พี่กานต์: พี่เพิ่งเห็น PR Terraform ของวันนี้... นายอ่าน plan ขาดมากอาร์เทอร์ พี่คิดไม่ผิดจริงๆ ที่ฝากทีม Blue ไว้กับนาย วันศุกร์นี้ลุยศึก Black Friday ให้เต็มที่นะ ท่านแม่ทัพ!

อาร์เทอร์มองข้อความนั้นด้วยรอยยิ้มภูมิใจ

ตอนนี้ทั้งอาวุธ GitHub Actions, Argo CD, Helm, AWS EKS, และ Terraform ได้เข้ามาอยู่ในมือของเขาอย่างสมบูรณ์แล้ว... ไม่ว่าพายุในวันศุกร์นี้จะรุนแรงแค่ไหน คุณพ่อวัยสามสิบคนนี้ก็พร้อมที่จะยืนหยัดอยู่หน้าด่านเพื่อรับมือกับมัน!
