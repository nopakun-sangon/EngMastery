บทที่ 6: เงาของความขัดแย้งและกับดัก OutOfSync

เช้าวันจันทร์ของสัปดาห์ที่สองเริ่มต้นขึ้นด้วยบรรยากาศที่ต่างไปจากเดิม

อาร์เทอร์ไม่ได้เดินเข้าออฟฟิศด้วยความรู้สึกเหมือนลูกแกะหลงทางอีกแล้ว บนโต๊ะทำงานของเขามีสมุดโน้ตที่ถูกคั่นหน้าด้วยโพสต์อิทหลากสี แบ่งหมวดหมู่คำศัพท์เทคนิคและประโยคภาษาอังกฤษที่ใช้บ่อยไว้อย่างเป็นระเบียบ

แต่ความสงบสุขในโลกของ DevOps มักอยู่ได้ไม่นาน... โดยเฉพาะเมื่อมี "คนเก่งแต่ไม่เคารพกติกา" เข้ามาเกี่ยวข้อง

เวลา 11:15 น. (บ่ายสามโมงกว่าตามเวลาซิดนีย์)

"แปลกแฮะ..." พี่กานต์ขมวดคิ้วจ้องหน้าจอมอนิเตอร์ของตัวเอง "ทำไมกราฟการกิน CPU ของระบบจัดการสต็อกสินค้า (Inventory Service) ที่ซิดนีย์มันดูแปลกๆ เหมือนโค้ดที่รันอยู่บน AWS EKS ตอนนี้ ไม่ใช่เวอร์ชันเดียวกับที่อยู่ใน GitHub เลย"

อาร์เทอร์ที่กำลังนั่งศึกษาเรื่องการทำ Auto-scaling อยู่ รีบหันเก้าอี้ไปดู "อ้าว... แต่ในหน้าเว็บ Argo CD ของผม เจ้าปลาหมึกของระบบสต็อกสินค้ามันก็ขึ้นสีเขียว Synced ปกตินี่ครับพี่กานต์?"

"ไม่สิ ดูตรงนี้..." พี่กานต์ชี้ไปที่มุมเล็กๆ ของกล่องพอดตัวหนึ่งซึ่งมีสัญลักษณ์รูปเครื่องหมายตกใจสีเหลืองกะพริบขึ้นมาแวบหนึ่ง ก่อนจะเปลี่ยนสถานะเป็นคำว่า OutOfSync (ข้อมูลไม่ตรงกัน)!

"เฮ้ย! อยู่ดีๆ มันก็หลุด Sync เองเฉยเลยครับ!" ภพที่ชะโงกหน้ามาดูด้วยร้องขึ้น "ทั้งที่ไม่มีใครกดส่งโค้ดใหม่ใน GitHub เลยนะ!"

ในโลกของ GitOps ที่มี Argo CD เป็นผู้คุมกฎ กฎเหล็กเพียงข้อเดียวคือ "โค้ดใน Git คือความจริงสูงสุด (Single Source of Truth)" ห้ามใครแอบเข้าไปแก้ค่าในเซิร์ฟเวอร์ AWS EKS ด้วยมือโดยตรงเด็ดขาด เพราะถ้ามีคนแอบแก้ ค่าในเซิร์ฟเวอร์จริงจะไม่ตรงกับใน Git ทันที ซึ่งเรียกว่าอาการ Configuration Drift (การตั้งค่าเพี้ยน)

และตอนนี้... มีมือมืดกำลังแอบเข้าไปแก้ค่าบน Production ที่ซิดนีย์แบบสดๆ!

"อาร์เทอร์!" พี่กานต์หันมาสั่งเสียงเครียด "ใช้คำสั่งตรวจดูใน Argo CD เดี๋ยวนี้ว่าส่วนไหนของระบบสต็อกที่มันขึ้น OutOfSync แล้วดูซิว่าใครเป็นคนเข้าไปแก้!"

"ครับพี่!"

อาร์เทอร์สลับหน้าจอกลับมาที่เครื่องตัวเอง คลิกเข้าไปดูโหมดเปรียบเทียบโค้ด (Diff) ใน Argo CD ทันที หน้าจอแสดงแถบสีแดงและสีเขียวเปรียบเทียบกันชัดเจน... มีใครบางคนแอบใช้คำสั่งหลังบ้าน (kubectl edit) เจาะเข้าไปเปลี่ยนที่อยู่ของฐานข้อมูลและปิดระบบตรวจสอบความปลอดภัยบางตัวใน AWS EKS โดยตรง!

และที่น่ากลัวกว่านั้นคือ... ทันทีที่คนคนนั้นแอบแก้เสร็จ เจ้าปลาหมึก Argo CD ซึ่งถูกตั้งค่าระบบรักษาความปลอดภัยอัตโนมัติ (Self-Heal) เอาไว้ ก็พยายามดึงค่าเก่าใน Git กลับมาทับภายใน 5 วินาที แต่คนคนนั้นก็ยังดื้อดึง พิมพ์คำสั่งยัดกลับเข้าไปใหม่อีก!

ส่งผลให้ตอนนี้ พอดของระบบสต็อกสินค้าที่ซิดนีย์กำลังถูกรีสตาร์ทสลับไปมาทุกๆ 10 วินาที เหมือนคนกำลังแย่งพวงมาลัยรถกันกลางทางด่วน!

ตือดึง! ตือดึง!

สัญญาณเตือนภัยระดับวิกฤตดังขึ้นอีกครั้ง ระบบหน้าเว็บของออสเตรเลียเริ่มสั่งซื้อของไม่ได้เพราะเช็กสต็อกไม่ผ่าน!

จังหวะเดียวกับที่ ‘ซัน’ หัวหน้าทีมสีแดง (Red Team) เดินถือแก้วกาแฟผ่านมาพอดี เขาชะโงกหน้ามามองจอของอาร์เทอร์แล้วผิวปากหวือ "โอ้โห ศึกชิงเจ้ายุทธภพเหรอวะกานต์ ใครแอบยิง kubectl สู้กับ Argo CD บน Production วะนั่น โคตรห้าว!"

"ราจ! ช่วยเช็ก AWS CloudTrail (บันทึกประวัติการใช้งาน) ให้ทีว่าแอ็กเคานต์ใครกำลังยิงคำสั่งเข้า EKS ตอนนี้!" พี่กานต์ตะโกนบอกหนุ่มอินเดียในทีม

นิ้วของราจรัวบนคีย์บอร์ดไม่ถึงสิบวินาที ก่อนจะเงยหน้าขึ้นมาด้วยสีหน้าลำบากใจ

"Karn... It's Marcus. The new Senior Architect in Sydney who just joined last week."(กานต์... เป็นมาร์คัสครับ สถาปนิกอาวุโสคนใหม่ที่ซิดนีย์ที่เพิ่งเข้ามาทำงานเมื่อสัปดาห์ก่อน)

ชื่อของ ‘มาร์คัส’ ทำเอาทั้งพี่กานต์และภพหน้าตึงขึ้นมาทันที มาร์คัสคือโปรแกรมเมอร์ระดับอาวุโสชาวออสเตรเลียที่เพิ่งถูกดึงตัวมาด้วยค่าตัวแพงลิ่ว มีอีโก้สูง และไม่ค่อยชอบระบบ GitOps ที่ต้องรอผ่านกระบวนการตรวจสอบ เพราะคิดว่าเป็นเรื่องเสียเวลาสำหรับคนเก่งๆ อย่างเขา

ทันใดนั้น หน้าต่างห้องประชุมฉุกเฉิน War Room ก็เด้งขึ้นมา และคนที่เปิดไมค์พูดคนแรกด้วยน้ำเสียงหงุดหงิดสุดขีดก็คือ มาร์คัส!

"What the hell is wrong with your Kubernetes cluster, Thailand team?!"
เสียงทุ้มต่ำและเกรี้ยวกราดของมาร์คัสดังลั่นห้องประชุม "I'm trying to apply an urgent performance tweak directly to the inventory pods, and your stupid Argo CD keeps overwriting my changes! Turn that garbage off right now! You're blocking my work!"(คลัสเตอร์ Kubernetes ของพวกคุณเป็นบ้าอะไรเนี่ยทีมไทย?! ผมกำลังพยายามปรับแต่งค่าด่วนลงไปที่พอดของระบบสต็อกโดยตรง แต่ไอ้ Argo CD โง่ๆ ของพวกคุณเอาแต่เขียนทับค่าของผม! ปิดไอ้ระบบขยะนั่นเดี๋ยวนี้! พวกคุณกำลังขวางการทำงานของผมนะ!)

บรรยากาศในห้องประชุมออนไลน์เย็นยะเยือก เลียมยังไม่ทันได้เข้ามาในสาย มีเพียงโคลอี้ที่พยายามพูดแทรกขึ้นเบาๆ แต่ก็โดนมาร์คัสตัดบท

มาร์คัสกำลังใช้ตำแหน่งที่อาวุโสกว่า บีบให้ทีม Blue ในไทยยอมจำนนและปิดระบบ Argo CD ทิ้ง!

พี่กานต์ขบกรามแน่น กำลังจะกดเปิดไมค์เพื่อโต้ตอบ แต่ในจังหวะนั้นเอง เสียงเตือนจากจอมอนิเตอร์ของอาร์เทอร์ก็ดัง ปี๊บ! ขึ้นมา

อาร์เทอร์ไม่ได้มองแค่หน้าจอ Argo CD... แต่เขาเปิดหน้าต่างดูบันทึกความผิดพลาด (Logs) ของพอดที่มาร์คัสพยายามแก้ค่าลงไปควบคู่กันไปด้วย และสายตาของเขาก็ดันไปเห็นบรรทัดสีแดงบรรทัดหนึ่งที่ซ่อนอยู่!

"พี่กานต์ครับ! ห้ามปิด Argo CD เด็ดขาดนะครับ!" อาร์เทอร์โพล่งขึ้นมาเสียงดัง มือชี้ไปที่หน้าจอของตัวเอง

"คุณมาร์คัสเขาพิมพ์ชื่อตัวแปรเชื่อมต่อฐานข้อมูลผิดครับ! เขาพิมพ์คำว่า PROD_DB_SYDNEY เป็น PROD_DB_SYDENY (ตัว N กับตัว E สลับกัน)! ที่ระบบสต็อกยังรอดอยู่ทุกๆ 10 วินาทีตอนนี้ เพราะเจ้าปลาหมึก Argo CD ของเราพยายามดึงค่าที่ถูกต้องกลับมาช่วยชีวิตไว้ครับ ถ้าเราปิด Argo CD ตามที่เขาสั่ง... ระบบสต็อกทั้งหมดของออสเตรเลียจะดับสนิททันที!"

พี่กานต์เบิกตากว้าง ก้มลงมองหน้าจอของอาร์เทอร์ "จริงด้วย! มาร์คัสแก้สดบนเซิร์ฟเวอร์โดยไม่ผ่านระบบตรวจคำผิดใน GitHub Actions มันเลยพิมพ์ผิดแล้วไม่รู้ตัว!"

"Hey! Are you guys deaf in Bangkok?! I said turn off Argo CD sync NOW!"(เฮ้! ที่กรุงเทพฯ หูหนวกกันหรือไง?! ผมสั่งให้ปิดการซิงค์ของ Argo CD เดี๋ยวนี้!)
มาร์คัสตวาดซ้ำเข้ามาในไมโครโฟน น้ำเสียงดูถูกเหยียดหยามอย่างชัดเจนจนภพกำหมัดแน่นด้วยความโกรธ

อาร์เทอร์มองเห็นความกดดันบนใบหน้าของพี่กานต์ ในฐานะหัวหน้าทีมคนไทย ถ้าพี่กานต์ปะทะกับสถาปนิกใหญ่ชาวต่างชาติตรงๆ อาจกลายเป็นปัญหาการเมืองระหว่างออฟฟิศได้...

แต่คนที่เห็นหลักฐานคาตาอยู่ตรงหน้าคือเขา!

อาร์เทอร์นึกถึงคำสอนของพี่กานต์เมื่อสัปดาห์ก่อน... ‘คนทำงานสายเทคนิค เราคุยกันด้วยหลักฐานและ Log’ แม้ภาษาอังกฤษของเขาจะยังไม่สละสลวย แต่เขาจะไม่ยอมให้ฝรั่งขี้โมโหคนนี้มาดูถูกทีมของเขา และพังระบบที่เขาดูแลอยู่เด็ดขาด!

อาร์เทอร์เอื้อมมือไปกดปุ่ม Share Screen (แชร์หน้าจอ) ของตัวเองขึ้นไปกลางห้องประชุม War Room ทันที!

หน้าจอดำมืดที่ซูมขยายบรรทัดสีแดงคำว่า UnknownHostException: PROD_DB_SYDENY ปรากฏหราขึ้นต่อหน้าผู้ร่วมประชุมทุกคนทั้งในไทยและออสเตรเลีย!

"No, Marcus! We cannot turn off Argo CD!"

เสียงของอาร์เทอร์กังวานขึ้นในไมโครโฟน แม้สำเนียงจะแปร่งๆ แบบคนไทยแท้ๆ แต่น้ำเสียงของชายวัยสามสิบกลับนิ่งและหนักแน่นจนมาร์คัสชะงักกึก

"Look at my screen!" อาร์เทอร์พูดต่อช้าๆ ชัดๆ ทีละคำ พร้อมใช้เมาส์วงกลมสีแดงรอบคำที่พิมพ์ผิด "You made a typo in kubectl edit. You typed S-Y-D-E-N-Y instead of S-Y-D-N-E-Y!"(ดูที่หน้าจอของผม! คุณพิมพ์ผิดในคำสั่งแก้ไข คุณพิมพ์ S-Y-D-E-N-Y แทนที่จะเป็น S-Y-D-N-E-Y!)

อาร์เทอร์สูดหายใจลึก แล้วปล่อยหมัดฮุกสุดท้ายด้วยประโยคที่เขาเพิ่งอ่านเจอในคู่มือเมื่อเช้า

"Argo CD is not garbage. It is saving Production from your typo right now! Please... stop editing the cluster directly and use GitHub Pull Request!"(Argo CD ไม่ใช่ขยะ แต่มันกำลังช่วยชีวิตเซิร์ฟเวอร์จริงจากคำที่นายพิมพ์ผิดอยู่ต่างหาก! ได้โปรดหยุดแก้เซิร์ฟเวอร์โดยตรง แล้วส่งโค้ดผ่าน GitHub ตามขั้นตอนด้วยครับ!)

ความเงียบงันเข้าปกคลุมห้องประชุมออนไลน์ทั้งสองซีกโลก!

ภพที่นั่งอยู่ข้างๆ อ้าปากค้าง มองอาร์เทอร์เหมือนเห็นพระเจ้าลงมาจุติ ส่วนราจยกมือขึ้นปิดปากกลั้นยิ้มสุดชีวิต

หลักฐานคาตาขนาดนั้น ต่อให้เป็นสถาปนิกระดับเทพก็เถียงไม่ออก บนหน้าจอที่แชร์อยู่ ทุกคนเห็นชัดเจนว่ามาร์คัสเป็นคนพิมพ์ชื่อเมืองซิดนีย์ผิดเองกับมือ และถ้าระบบ Argo CD ที่ทีมไทยดูแลอยู่ไม่คอยดึงค่ากลับ ระบบคงล่มสลายไปแล้วจริงๆ!

"I... uh..." เสียงของมาร์คัสที่เคยเกรี้ยวกราดเมื่อครู่ อึกอักอยู่ในลำคอ หน้าตาในกล้องเว็บแคมแดงก่ำด้วยความอับอาย

และในจังหวะนั้นเอง เสียงของสองผู้พิทักษ์กติกาของบริษัทที่เพิ่งเข้ามาอยู่ในสายเงียบๆ ได้สักพักก็ดังขึ้นพร้อมกัน!

"Well said, Arthur." เสียงทุ้มของ ‘เลียม’ หัวหน้าใหญ่ฝั่งออสเตรเลียดังขึ้นด้วยน้ำเสียงเย็นชาแต่ทรงอำนาจ "Marcus, nobody bypasses our GitOps pipeline on my watch. Not even a Senior Architect."(พูดได้ดีมากอาร์เทอร์... มาร์คัส ไม่มีใครหน้าไหนได้รับอนุญาตให้ข้ามขั้นตอน GitOps ในเขตความรับผิดชอบของผม แม้แต่สถาปนิกอาวุโสก็ตาม)

ตามมาด้วยเสียงเย็นยะเยือกของ ‘เอเลน่า’ หัวหน้าทีมสีเขียวที่เปิดไมค์พูดเสริมทันที:"And Marcus, Green Team is revoking your direct kubectl edit permission on Production effective immediately.
