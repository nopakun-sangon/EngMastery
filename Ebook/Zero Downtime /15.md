บทที่ 15: สองชั่วโมงตัดสินชะตาบนหน้าจอดำ

คืนวันอาทิตย์ เวลา 20:30 น.

แตกต่างจากการสอบ AWS ที่ต้องเดินทางไปที่ศูนย์สอบ การสอบ CKA (Certified Kubernetes Administrator) นั้นโหดหินและกดดันไปอีกแบบ เพราะมันคือการสอบออนไลน์จากที่บ้าน โดยต้องเปิดกล้องเว็บแคมและไมโครโฟนให้ผู้คุมสอบชาวต่างชาติ (Proctor) จับตาดูทุกความเคลื่อนไหวตลอด 2 ชั่วโมงเต็ม!

กฎของการสอบนี้เข้มงวดระดับสูงสุด... โต๊ะทำงานต้องโล่งเตียน ห้ามมีกระดาษโน้ตแม้แต่แผ่นเดียว ห้ามมีคนอื่นเดินเข้ามาในห้อง ห้ามพูดพึมพำออกเสียง และห้ามละสายตาออกจากหน้าจอเกินกำหนด ไม่อย่างนั้นจะถูกปรับตกทันที!

อาร์เทอร์ยกโต๊ะญี่ปุ่นมาตั้งในห้องนอนเล็ก จัดการเก็บของทุกอย่างออกจนเกลี้ยง เหลือเพียงโน้ตบุ๊กหนึ่งเครื่องและแก้วน้ำใสที่แกะฉลากออกแล้วตามกฎ

หน้าประตูห้อง น้องออกัสในชุดนอนลายไดโนเสาร์ยืนเกาะขอบประตูมองพ่อตาแป๋ว โดยมีแพรคอยจับไหล่ลูกชายไว้

"ปะป๊าครับ... คืนนี้ออกัสจะไม่ส่งเสียงดังเลย ออกัสจะเดินย่องๆ เหมือนนินจาให้ปะป๊าสอบผ่านนะครับ!" เด็กชายวัยหกขวบกระซิบเสียงเบาหวิวพร้อมทำท่าเดินย่องอวดพ่อ

อาร์เทอร์ยิ้มกว้างด้วยความเอ็นดู ย่อตัวลงไปจูบหน้าผากลูกชายและภรรยา "ขอบคุณครับนินจาออกัส ขอบคุณนะแพร... อีกสองชั่วโมงปะป๊าจะเอาชัยชนะออกมาอวดนะ"

ประตูปิดลง... ความเงียบสงัดเข้าปกคลุมห้องสี่เหลี่ยม

อาร์เทอร์นั่งลงหน้าโน้ตบุ๊ก กดเข้าสู่ระบบสอบ ผู้คุมสอบชาวต่างชาติสั่งให้เขาถือโน้ตบุ๊กหมุนโชว์สภาพห้องทั้งสี่ทิศ ส่องดูใต้โต๊ะ และตรวจข้อมือทั้งสองข้างผ่านข้อความแชทภาษาอังกฤษ เมื่อทุกอย่างผ่านเกณฑ์ หน้าต่างเบราว์เซอร์พิเศษที่ล็อกหน้าจอทั้งหมดก็เด้งขึ้นมา

ทางซ้ายมือคือโจทย์ภาษาอังกฤษข้อที่ 1 จากทั้งหมด 16 ข้อ... และทางขวามือคือหน้าจอเทอร์มินัลสีดำสนิทที่มีเคอร์เซอร์กะพริบ รอรับคำสั่ง!

Time Remaining: 02:00:00

อาร์เทอร์สูดลมหายใจเข้าลึกสุดปอด วินาทีที่เริ่มทำข้อแรก เขาพิมพ์คาถาตั้งคีย์ลัด alias k=kubectl ลงไปทันทีด้วยความเร็วแสง

ข้อที่ 1: สร้างพอดและจำกัดสิทธิ์ด้วย RBAC... นิ้วของอาร์เทอร์รัวคำสั่งเสกโค้ดอัตโนมัติ เสร็จภายใน 3 นาที!ข้อที่ 4: อัปเกรดคลัสเตอร์และใช้คำสั่ง drain อพยพพอด... ภาพตอนที่เขาทำบน AWS EKS เมื่อวันพฤหัสบดีซ้อนทับขึ้นมา เขาพิมพ์หางคำสั่ง --ignore-daemonsets ได้อย่างแม่นยำโดยไม่ต้องเปิดคู่มือดูแม้แต่วินาทีเดียว!ข้อที่ 9: เขียน NetworkPolicy ล้อมรั้วพอด... รอยยิ้มบางๆ ผุดขึ้นที่มุมปากของอาร์เทอร์ เขาระวังเรื่องเครื่องหมายขีด (-) และพอร์ต 53 ที่เคยช่วยเอเลน่าแก้มาแล้ว จนผ่านข้อนี้ไปได้อย่างลื่นไหล!

เวลาผ่านไปหนึ่งชั่วโมงครึ่ง อาร์เทอร์เก็บข้อสอบไปแล้วถึง 14 ข้อ เหลือเวลาอีกตั้ง 30 นาทีสำหรับ 2 ข้อสุดท้ายที่มีคะแนนรวมกันถึง 20%!

แต่สมกับเป็นด่านอรหันต์... ข้อที่ 15 และ 16 คือโจทย์ระดับบอสที่ชื่อว่า "การสำรองข้อมูลสมองกล (etcd backup & restore)" และ "การซ่อมแซมโหนดที่ตายสนิท (Broken Worker Node)"

ในข้อสุดท้าย โจทย์สั่งให้เขาเข้าไปซ่อมเครื่องเซิร์ฟเวอร์เครื่องหนึ่งที่ขึ้นสถานะว่า NotReady (ไม่พร้อมใช้งาน)

อาร์เทอร์รีโมต (ssh) เข้าไปในเครื่องที่พังนั้นทันที เขาลองเช็กสถานะของโปรแกรมจัดการโหนดที่ชื่อว่า kubelet ตามที่พี่กานต์เคยสอน... ปรากฏว่าโปรแกรมมันดับอยู่ เขาสั่งเปิดมันขึ้นมาใหม่ (systemctl restart kubelet) แต่พอนับหนึ่งถึงห้า มันก็ดับไปอีก!

เวลาบนมุมจอลดลงเหลือ 00:12:45

เหงื่อเม็ดเล็กๆ เริ่มผุดขึ้นที่ขมับของอาร์เทอร์ เขาจะพูดพึมพำกับตัวเองเพื่อระบายความเครียดก็ไม่ได้เพราะผู้คุมสอบจ้องอยู่ผ่านกล้องเว็บแคม

ใจเย็นไว้ไอ้อาร์เทอร์... เวลาโปรแกรมบนเซิร์ฟเวอร์มันเปิดแล้วดับ เราต้องดูอะไร? ดู Log ไงล่ะ!

อาร์เทอร์พิมพ์คำสั่ง journalctl -u kubelet -f เพื่อขอดูบันทึกความผิดพลาดของตัวเครื่องทันที ตัวหนังสือสีขาววิ่งพรืดขึ้นมาเต็มหน้าจอ ก่อนที่สายตาของเขาจะไปสะดุดเข้ากับบรรทัดที่ฟ้องว่า:

failed to load Kubelet config file /var/lib/kubelet/config.yaml: no such file or directory

อาร์เทอร์ขมวดคิ้ว รีบเข้าไปตรวจดูไฟล์ตั้งค่าของระบบ... แล้วเขาก็เห็นกับดักที่คนออกข้อสอบวางยาเอาไว้!

คนออกข้อสอบแอบพิมพ์ที่อยู่ไฟล์ในใบตั้งค่าผิด จากคำว่า /var/lib/kubelet/config.yaml ดันไปพิมพ์เป็น /var/lib/kubelet/config.yml (ตกตัว a ไปตัวเดียว)! เหมือนตอนที่มาร์คัสพิมพ์ชื่อเมืองซิดนีย์ผิดไม่มีผิดเพี้ยน!

เมื่อเจอต้นตอของเส้นผมบังภูเขา นิ้วของอาร์เทอร์ก็รัวแก้ไขชื่อไฟล์ให้ถูกต้อง สั่งรีสตาร์ทเซอร์วิสใหม่อีกครั้ง และสลับกลับมาพิมพ์คำสั่ง k get nodes เพื่อเช็กผลลัพธ์

หน้าจอดำมืดแสดงสถานะของเซิร์ฟเวอร์ทุกเครื่องเป็นคำว่า: Ready ครบทุกตัว!

เวลาเหลืออีก 3 นาทีสุดท้าย อาร์เทอร์ไล่ตรวจทานทุกข้อจนมั่นใจ แล้วกดปุ่มปิดหน้าต่างส่งข้อสอบทันทีที่เข็มวินาทีสุดท้ายกำลังจะหมดลง!

แต่สำหรับการสอบ CKA... ผลลัพธ์จะไม่ได้เด้งขึ้นมาทันทีเหมือนตอนสอบ AWS ระบบแจ้งว่าเขาต้องรอให้คอมพิวเตอร์ของสถาบัน Linux Foundation ตรวจให้คะแนนจากการทำงานจริงของคลัสเตอร์เป็นเวลา 24 ชั่วโมง!

วันจันทร์ เวลา 21:00 น. (หนึ่งวันหลังสอบ)

ตลอดทั้งวันจันทร์ที่ออฟฟิศ อาร์เทอร์ทำงานไปด้วยใจที่เต้นตุ้มๆ ต่อมๆ จนกระทั่งเขากลับมาถึงบ้าน อาบน้ำ กินข้าว และกำลังนั่งเล่านิทานก่อนนอนให้น้องออกัสฟังอยู่บนเตียง

อาร์เทอร์ชะงักการอ่านนิทาน หันไปสบตากับแพรที่เดินตามเข้ามาในห้องนอนพอดี มือของชายวัยสามสิบเอื้อมไปหยิบมือถือขึ้นมาด้วยความประหม่า

อาร์เทอร์กลั้นหายใจ กดเปิดอีเมลนั้นขึ้นมาดู...

ภาพใบประกาศนียบัตรสีน้ำเงินเข้มที่มีโลโก้พวงมาลัยเรือสีขาวของ Kubernetes ปรากฏขึ้นตรงหน้า พร้อมข้อความที่ทำให้หัวใจของเขาแทบจะกระโดดออกมาจากอก:

"แปดสิบแปดเปอร์เซ็นต์..." อาร์เทอร์พึมพำเสียงสั่น ก่อนจะหันไปชูหน้าจอมือถือให้ภรรยากับลูกชายดู "แพร! ออกัส! ปะป๊าสอบผ่านแล้ว! ได้ตั้งแปดสิบแปดคะแนนแน่ะ!"

"เย้!! นินจาออกัสช่วยปะป๊าสำเร็จแล้ว!" ลูกชายตัวน้อยกระโดดโลดเต้นบนที่นอนด้วยความดีใจ ก่อนจะโผเข้ามากอดคอพ่อแน่น แพรเองก็เข้ามากอดทั้งพ่อและลูกไว้ด้วยรอยยิ้มแห่งความภาคภูมิใจ

อาร์เทอร์แคปหน้าจอใบเซอร์ CKA ส่งเข้าไปในกลุ่มแชทของทีม Blue ทันที

ไม่ถึงสิบวินาที เสียงแจ้งเตือนข้อความแสดงความยินดีก็เด้งรัวๆ จนมือถือสั่นไม่หยุด ทั้งพี่กานต์ ภพ ราจ โคลอี้ เอเลน่า และเลียม ต่างส่งอิโมจิรูปถ้วยรางวัล 🏆 และพลุฉลองมาให้เขากันยกใหญ่
