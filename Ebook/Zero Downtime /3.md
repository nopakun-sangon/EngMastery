บทที่ 3: ลมหายใจเฮือกสุดท้ายของคุณปู่ Jenkins

"อ็อกซ์... ฮอสพิทอล... แปลว่าโรงพยาบาลวัวเหรอครับปะป๊า?"

เสียงถามซื่อๆ ของน้องออกัสที่กำลังนั่งก้มหน้าก้มตาวาดรูประบายสีอยู่บนโต๊ะกินข้าว ทำเอาอาร์เทอร์ที่กำลังนั่งท่องศัพท์ภาษาอังกฤษอยู่ข้างๆ ถึงกับหลุดขำพรืดออกมา

แพรที่กำลังยืนล้างจานอยู่หันมายิ้มตาม "ลูกไปเอาคำนี้มาจากไหนครับออกัส?"

"ปะป๊าเปิดในมือถือเมื่อกี้ครับ มีฝรั่งพูดคำว่าฮอสพิทอลๆ" เด็กชายวัยหกขวบชี้ไปที่โทรศัพท์ของพ่อ

"ไม่ใช่โรงพยาบาลวัวลูก..." อาร์เทอร์หัวเราะ ยื่นมือไปลูบหัวลูกชาย "ในคลิปเขาพูดว่า Out of commission ต่างหาก แปลว่าพัง หรือใช้งานไม่ได้ชั่วคราวครับ พอดีฝรั่งเขาพูดรวบคำเร็วไปหน่อย ปะป๊าเองก็ฟังรอบที่ห้าถึงจะแกะออกเหมือนกัน"

ตั้งแต่ผ่านวันแรกในทีม Blue มาได้ กิจวัตรยามค่ำคืนของอาร์เทอร์ก็เปลี่ยนไป หลังจากกินข้าวและช่วยดูการบ้านลูกเสร็จ เขากับออกัสจะมานั่งที่โต๊ะตัวเดียวกัน คนลูกฝึกคัด ก.ไก่ ถึง ฮ.นกฮูก ส่วนคนพ่อวัยสามสิบฝึกฟังคลิปสนทนาภาษาอังกฤษของคนสายไอที พร้อมกับจดคำศัพท์เทคนิคลงสมุดโน้ต

แม้จะเหนื่อยจนหนังตาแทบปิด แต่ทุกครั้งที่เห็นลูกชายตั้งใจเขียนหนังสือ อาร์เทอร์ก็บอกตัวเองว่าเขาจะแอบอู้ไม่ได้เด็ดขาด

เช้าวันอังคาร เวลา 09:05 น.

"อ้าวเฮ้ย... ทำไมหน้าเว็บคุณปู่มันหมุนติ้วๆ แบบนี้ล่ะ"

เสียงของภพดังขึ้นหลังจากเพิ่งกดวางสายประชุม Daily Standup กับฝั่งออสเตรเลียไปได้ไม่ถึงห้านาที

อาร์เทอร์ชะโงกหน้าไปดูจอของรุ่นน้อง บนหน้าจอคือเว็บ Jenkins ตัวเดียวกับที่อาร์เทอร์เพิ่งหัดกดเมื่อวาน แต่วันนี้มันกลับขึ้นหน้าจอสีขาวโพลน พร้อมข้อความตัวโตๆ ว่า 504 Gateway Time-out

ไม่ทันขาดคำ เสียงแจ้งเตือนในกลุ่มแชท Slack ของทีม Blue ก็เด้งรัวๆ ขึ้นมาเหมือนปืนกล

Chloe (ANZ-Dev): Hey Blue team, is Jenkins down again? I need to deploy a hotfix for the Sydney promotion campaign before lunch!
(ทีม Blue จ๋า Jenkins ล่มอีกแล้วเหรอ? ฉันต้องรีบอัปเดตโค้ดแก้บั๊กด่วนสำหรับแคมเปญโปรโมชันของซิดนีย์ก่อนเที่ยงนะ!)

ที่ซิดนีย์ตอนนี้คือเวลาบ่ายโมงนิดๆ แคมเปญลดราคาช่วงพักเที่ยงกำลังมีลูกค้าเข้ามาใช้งานกันอย่างหนาแน่น แต่ระบบหลังบ้านดันมีบั๊กที่โคลอี้ต้องรีบส่งโค้ดใหม่ขึ้นไปแก้ และตัวกลางในการแพ็กโค้ดอย่าง Jenkins ดันมาหัวใจวายเอาตอนนี้พอดี!

"งานเข้าแล้วไง..." พี่กานต์ขมวดคิ้ว รีบหันมาสั่งการทันที "ภพ รีบ SSH เข้าไปดูเซิร์ฟเวอร์ Jenkins ซิว่าตายเพราะอะไร ส่วนอาร์เทอร์ เปิดหน้าจอดูตามภพไปด้วยเลย จะได้รู้วิธีเช็กอาการเซิร์ฟเวอร์เวลาเกิดเหตุฉุกเฉิน"

"ครับพี่!" อาร์เทอร์รับคำ รีบเลื่อนเก้าอี้เข้าไปประกบข้างภพพร้อมสมุดโน้ตคู่ใจ

นิ้วของภพรัวคำสั่งลงบนหน้าจอดำมืดอย่างรวดเร็วเพื่อเข้าไปดูสภาพเครื่องเซิร์ฟเวอร์ที่รัน Jenkins อยู่

"พี่กานต์ ดิสก์เต็ม 100% เลยครับ! แถมหน่วยความจำ (RAM) ก็พุ่งชนเพดานจนเครื่องค้างไปแล้ว เพราะมีงาน Build จากทีมอื่นค้างอยู่ในคิวเป็นสิบงานเลย" ภพหันมารายงานเสียงเครียด

"ท่าทางจะอาการหนักแฮะ..." พี่กานต์ก้มลงมองหน้าจอ "อาร์เทอร์ จำคำสั่งเช็กพื้นที่ดิสก์ใน Linux ได้ไหม?"

"จำได้ครับพี่ df -h ใช่ไหมครับ" อาร์เทอร์ตอบทันที เพราะนี่คือความรู้พื้นฐานไม่กี่อย่างจากงานเก่าที่เขายังพอเอามาใช้ได้

"เยี่ยมมาก งั้นอาร์เทอร์เอาคีย์บอร์ดไปลองพิมพ์หาโฟลเดอร์ที่กินพื้นที่เยอะที่สุด แล้วสั่งเคลียร์ไฟล์ขยะของการ Build รอบเก่าๆ ทิ้งไปก่อน เดี๋ยวพี่กับภพจะช่วยกันสั่งรีสตาร์ทเซอร์วิสให้โคลอี้ใช้งานเฉพาะหน้าไปก่อน"

มือของอาร์เทอร์สั่นเล็กน้อยเมื่อต้องมาจับคีย์บอร์ดแก้ปัญหาท่ามกลางสถานการณ์ที่ฝั่งออสเตรเลียกำลังรออยู่ แต่ด้วยคำแนะนำทีละสเต็ปของพี่กานต์ เขาก็ค่อยๆ พิมพ์คำสั่งลบไฟล์อิมเมจเก่าๆ ที่ค้างอยู่ในเครื่องออกไปได้สำเร็จ พื้นที่ดิสก์ลดลงมาเหลือ 60% และหน้าเว็บคุณลุงพ่อบ้าน Jenkins ก็กลับมามีชีวิตอีกครั้ง

โคลอี้ส่งสติกเกอร์ขอบคุณรัวๆ มาในแชทเมื่อเธอสามารถส่งโค้ดแก้บั๊กขึ้นไปที่ AWS EKS ได้ทันเวลาพอดี

แต่เรื่องยังไม่จบแค่นั้น...

สิบนาทีต่อมา เสียงเรียกเข้าจากโปรแกรมประชุมออนไลน์ก็ดังขึ้นที่เครื่องของพี่กานต์ อาร์เทอร์ และภพ คนที่โทรเข้ามาคือ ‘เลียม’ หัวหน้าใหญ่ฝั่งออสเตรเลีย

"Good job on the quick recovery, team," เลียมเปิดฉากด้วยน้ำเสียงจริงจัง แม้จะชมเชยแต่แววตาของเขาดูเหนื่อยหน่ายกับปัญหานี้เต็มทน "But we can't keep babysitting this old Jenkins server anymore. Every time it crashes, our deployment stops."

อาร์เทอร์ตั้งใจฟังอย่างสุดความสามารถ วันนี้เขาจับคำศัพท์ของเลียมได้มากขึ้นกว่าเมื่อวาน เลียมกำลังบอกว่า... เราจะมานั่งคอยประคบประหงมเซิร์ฟเวอร์ Jenkins แก่ๆ ตัวนี้ต่อไปไม่ไหวแล้ว ทุกครั้งที่มันพัง งานของเราก็ชะงักไปด้วย

"Karn, I want Blue Team to accelerate the migration to GitHub Actions (GHA) this week," เลียมหันมามองที่กล้องของอาร์เทอร์ "Arthur, since you successfully handled the payment-service yesterday, how about taking ownership of migrating its pipeline from Jenkins to GitHub Actions? Think of it as your first real project."

หัวใจของอาร์เทอร์เต้นแรงขึ้นมาทันที

Migrate... ย้ายระบบจาก Jenkins ไป GitHub Actions... แถมให้เขารับผิดชอบเป็นโปรเจกต์แรก!

พี่กานต์หันมามองหน้าอาร์เทอร์เหมือนจะถามความเห็นด้วยสายตา อาร์เทอร์กลืนน้ำลายลงคอ เขารู้ดีว่าตัวเองยังไม่เป็น GitHub Actions เลยสักนิด แต่ถ้าเขาปฏิเสธโอกาสนี้ เขาก็จะเป็นได้แค่คนคอยกดปุ่มตามคำสั่งไปวันๆ

อาร์เทอร์กดเปิดไมค์ สูดหายใจลึก แล้วพูดประโยคภาษาอังกฤษที่เขาเพิ่งซ้อมพูดหน้ากระจกเมื่อคืนออกมาอย่างฉะฉาน

"I will... do my best, Liam. Thank you."

รอยยิ้มกว้างปรากฏขึ้นบนใบหน้าของหัวหน้าชาวออสซี่ทันที "That's the spirit, mate! Karn will help you get started. Cheers!"

เมื่อหน้าต่างประชุมปิดลง ภพก็หันมาปรบมือแปะๆ ให้อาร์เทอร์ "หูยยย พี่อาร์เทอร์โคตรเท่! รับจบงานใหญ่ซะด้วย"

"เท่อะไรล่ะภพ พี่ตื่นเต้นจนมือเย็นไปหมดแล้วเนี่ย" อาร์เทอร์ยิ้มแหยๆ ก่อนจะหันไปหาพี่เลี้ยงคนสำคัญ "พี่กานต์ครับ... ไอ้เจ้า GitHub Actions เนี่ย มันต่างจากคุณลุง Jenkins ยังไง แล้วผมต้องเริ่มจากตรงไหนครับ?"

พี่กานต์ยกแก้วกาแฟขึ้นมาจิบ ก่อนจะหมุนเก้าอี้มาหาพร้อมรอยยิ้มของอาจารย์ที่กำลังจะถ่ายทอดวิชาขั้นต่อไป

"จำได้ไหมที่เมื่อกี้เราต้องเข้าไปลบไฟล์ขยะในเซิร์ฟเวอร์ Jenkins เพราะดิสก์มันเต็ม?" พี่กานต์ถาม

"จำได้ครับ"

"นั่นแหละคือข้อเสียของ Jenkins ยุคเก่า เราต้องมีเซิร์ฟเวอร์หนึ่งเครื่องเปิดทิ้งไว้ตลอดเวลาเพื่อเป็นโรงงานแพ็กโค้ด พอคนใช้เยอะโรงงานก็พัง ดิสก์ก็เต็ม แถมต้องคอยซ่อมบำรุงเอง" พี่กานต์เปิดหน้าเว็บ GitHub ขึ้นมาบนจอ แล้วชี้ไปที่เมนูคำว่า Actions ที่มีสัญลักษณ์เป็นรูปปุ่ม Play

"แต่ GitHub Actions คือยุคใหม่... เราไม่ต้องมีเซิร์ฟเวอร์โรงงานของตัวเองอีกต่อไปแล้ว ทันทีที่โคลอี้ส่งโค้ดเข้ามาใน GitHub ระบบของ GitHub จะเสกเครื่องเซิร์ฟเวอร์ชั่วคราวขึ้นมาให้เรา 1 เครื่อง ทำการแพ็กโค้ดเป็น Docker Image ส่งไปเก็บที่ AWS ให้เสร็จสรรพ แล้วมันก็ทำลายเซิร์ฟเวอร์ชั่วคราวนั้นทิ้งทันที... ดิสก์ไม่มีวันเต็ม ไม่ต้องคอยรีสตาร์ทเครื่อง และไม่เสียเวลาพวกเราด้วย"

ดวงตาของอาร์เทอร์เบิกกว้างขึ้นด้วยความทึ่ง "โห... เสกเครื่องขึ้นมาใช้แล้วทิ้งเลยเหรอครับ แบบนี้เราก็ไม่ต้องมานั่งเฝ้าเซิร์ฟเวอร์เหมือนเมื่อกี้แล้วสิครับ!"

"ถูกต้อง!" พี่กานต์ดีดนิ้ว "แต่การจะสั่งให้มันทำงานตามที่เราต้องการได้ เราไม่ได้เข้าไปกดปุ่มบนหน้าเว็บเหมือน Jenkins แล้วนะ เราต้องเขียน 'ใบสั่งงาน' ทิ้งไว้ในโปรเจกต์ด้วยไฟล์ที่ชื่อว่า YAML"

พี่กานต์ดึงกระดาษโพสต์อิทแผ่นใหม่ออกมา เขียนโจทย์ประจำสัปดาห์นี้แปะทับแผ่นเก่าของเมื่อวาน:

สร้างไฟล์ .github/workflows/deploy.yml

สั่งให้มันทำงานอัตโนมัติเมื่อโคลอี้แก้โค้ด (on: push)

สั่งให้มันเชื่อมต่อกับ AWS เพื่อส่งกล่องโค้ดไปเก็บ (AWS IAM & ECR)

"งานนี้ยากกว่าเมื่อวานหลายเท่า เพราะอาร์เทอร์ต้องเขียนโค้ดสั่งการมันเองทั้งหมด และด่านที่ยากที่สุดคือข้อ 3... ถ้าตั้งค่าสิทธิ์ความปลอดภัยของ AWS ไม่ผ่าน เอเลน่า หัวหน้าทีมสีเขียว (Green Team) เอาตายแน่นอน" พี่กานต์ตบไหล่เขาเบาๆ

"มีเวลาถึงวันศุกร์นี้... ลองไปงมดูว่าเขียนใบสั่งงานให้ GitHub Actions ยังไง ติดตรงไหนมาถามพี่ ลุยได้!"

อาร์เทอร์มองโพสต์อิทใบใหม่ที่ขอบจอ ความกลัวเมื่อวันแรกหายไปแล้ว เหลือเพียงความท้าทายของโปรแกรมเมอร์วัยสามสิบที่กำลังจะได้จับเครื่องมือระดับโลกด้วยมือของตัวเองเป็นครั้งแรก!
