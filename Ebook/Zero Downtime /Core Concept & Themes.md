Zero Downtime คุณพ่อวัย 30 กับภารกิจกู้ชีพ (การงาน)

1. แก่นเรื่องและจุดขาย (Core Concept & Themes)
แนวเรื่อง (Genre): Workplace Drama / IT Progression (นิยายชีวิตคนทำงานที่ตัวเอกค่อยๆ อัปสกิลแก้ปัญหาเหมือนการปราบบอสในเกม)

ธีมหลัก: การก้าวข้ามขีดจำกัดในวัย 30 ปี ของหัวหน้าครอบครัวที่ต้นทุนต่ำ ทั้งการเรียนรู้เทคโนโลยีระดับโลก (Cloud/DevOps) และการทลายกำแพงภาษาอังกฤษเพื่อความอยู่รอดของครอบครัว

สูตรการเดินเรื่อง (The Story Loop):

ได้รับโจทย์ใหม่ หรือ เกิดปัญหาหน้างาน (Incident) จากฝั่งออสเตรเลีย

ความรู้เดิมใช้ไม่ได้ หรือติดกำแพงภาษา/เทคนิค

พี่เลี้ยงชี้เป้าคีย์เวิร์ด -> ตัวเอกไปค้นคว้า ทดลองทำ และฝึกภาษาอย่างหนัก

แก้ปัญหาสำเร็จ ระบบนิ่งขึ้น ได้รับการยอมรับ และได้สกิลใหม่ติดตัว

2. ข้อมูลตัวเอกและครอบครัว (The Protagonist)
ชื่อ: อาร์เทอร์ (Arthur) อายุ 30 ปี

ปมหลัง: จบจากมหาวิทยาลัยเล็กๆ ท้ายตาราง ทำงานเป็นโปรแกรมเมอร์ยุคเก่าในบริษัทไทยมาตลอด พอถูกบริษัทข้ามชาติเทคโอเวอร์ แผนกเดิมถูกยุบ จึงต้องย้ายมาทำตำแหน่ง Junior DevOps Engineer เพื่อรักษาเงินเดือนไว้ผ่อนบ้านและส่งลูกเรียน

จุดอ่อน: ไม่มีความรู้เรื่อง Cloud/DevOps ยุคใหม่เลย และภาษาอังกฤษอ่อนมาก (ฟังสำเนียงฝรั่งไม่ทัน กลัวการพูดและพิมพ์)

นิสัยเด่น: ขยัน อดทน ไม่เก๊ก (ไม่รู้ก็กล้าถาม) รักครอบครัว พยายามบริหารเวลาให้เลิกงานตรงเวลา (17:30 น.) เพื่อกลับไปหาลูกเมีย

ครอบครัว (แรงผลักดันสำคัญ):

แพร: ภรรยาคู่ชีวิตที่คอยให้กำลังใจและดูแลหลังบ้าน

น้องออกัส: ลูกชายวัย 6 ขวบ (กำลังจะเข้า ป.1) ที่มองพ่อเป็นฮีโร่เสมอ

3. โครงสร้างองค์กรและตัวละครในออฟฟิศ (15 คน / 3 ทีม)
ทำงานในบริษัทเทคโนโลยีข้ามชาติ แผนก Infrastructure & DevOps แบ่งเป็น 3 ทีม (Red, Blue, Green) โดยอาร์เทอร์อยู่ใน 🟦 Blue Team ที่ดูแลโปรเจกต์หลักของประเทศ ออสเตรเลีย (ANZ Region) ซึ่งเวลาเร็วกว่าไทย 3-4 ชั่วโมง (เริ่มงาน 08:30 น. เวลาไทย คือเที่ยงครึ่งที่ซิดนีย์ ทราฟฟิกกำลังพีคพอดี)

สมาชิกหลักใน 🟦 Blue Team (ทีมของอาร์เทอร์):

เลียม (Liam - ชาวออสเตรเลีย วัย 38 ปี): หัวหน้าใหญ่ฝั่ง ANZ ประจำที่เมลเบิร์น สไตล์ออสซี่เป็นกันเองแต่มาตรฐานงานสูง เป็นคนโยนโจทย์ใหญ่ๆ และเทคโนโลยีใหม่ๆ มาให้อาร์เทอร์ (ตัวฝึกภาษาชั้นดีของพระเอก)

พี่กานต์ (Karn - คนไทย วัย 32 ปี): หัวหน้าทีม Blue ฝั่งไทย นั่งข้างอาร์เทอร์ เป็น พี่เลี้ยงหลัก (Mentor) ที่คอยสกรีนงาน แนะนำคีย์เวิร์ดให้ไปค้นคว้าต่อ และคอยดันหลังให้อาร์เทอร์กล้าลุยด้วยตัวเอง

ภพ (Phop - คนไทย วัย 26 ปี): รุ่นน้องตำแหน่ง Mid-level DevOps นั่งอีกข้างของอาร์เทอร์ คุยสนุก ชอบกินชานมไข่มุก เป็นคู่หูคอยช่วยดูหน้างานและแปลศัพท์แสลงออฟฟิศให้

โคลอี้ (Chloe - ชาวออสเตรเลีย วัย 29 ปี): Senior Developer ฝั่งซิดนีย์ คนส่งมอบโค้ดมาให้ทีมอาร์เทอร์เอาขึ้นระบบ พูดตรงไปตรงมาแต่แฟร์มาก

ราจ (Raj - ชาวอินเดีย วัย 30 ปี): ผู้เชี่ยวชาญด้าน Database และ AWS ประจำออฟฟิศไทย พี่ชายใจดีที่พูดอังกฤษเร็วปรื๋อ

ตัวละครเสริมจากทีมสีอื่น:

🟥 ซัน (Red Team Lead - คนไทย): สายลุย ดูแลภูมิภาค SEA ที่ไฟไหม้บ่อย ชอบลองของใหม่

🟩 เอเลน่า (Green Team Lead - ยุโรปตะวันออก): สาวเฮี้ยบผู้คุมกฎ Security และ Network Firewall ด่านตรวจสำคัญที่อาร์เทอร์ต้องผ่านให้ได้

4. เนื้องานและเส้นทางการอัปเลเวล (Tech Stack & Story Arcs)
ระบบหลักรันอยู่บน AWS (ซิดนีย์) โดยมีแกนหลักคือการย้ายจากระบบเก่าไปสู่ระบบใหม่:

Arc 1: ปรับตัวและเอาตัวรอดในโลกใบใหม่ (บทที่ 1-3)

เนื้อหา: ทำความรู้จักการทำงานข้ามไทม์โซน การประชุม Daily Standup ภาษาอังกฤษ และการเชื่อมโยงระหว่าง Jenkins -> Argo CD -> AWS EKS

ปัญหาที่แก้: แก้อาการพอดรันไม่ขึ้น (CrashLoopBackOff), หัดอ่าน Log ใน Kubernetes, และทลายความกลัวในการพิมพ์แชทภาษาอังกฤษคุยกับโคลอี้เป็นครั้งแรก

Arc 2: โละคุณปู่ Jenkins สู่ยุคใหม่ด้วย GitHub Actions (บทที่ 4-6)

เนื้อหา: เซิร์ฟเวอร์ Jenkins รุ่นเก่าเริ่มรวนและค้างบ่อย เลียมจึงสั่งให้เริ่มโปรเจกต์ย้ายระบบ CI ไปใช้ GitHub Actions (GHA)

ปัญหาที่แก้: อาร์เทอร์ได้รับมอบหมายให้เขียนไฟล์ Workflow (.yaml) ตัวแรกเพื่อ Build Docker Image ส่งขึ้น AWS ECR ต้องเรียนรู้เรื่องการตั้งค่าตัวแปรและสิทธิ์การเข้าถึง (IAM Role)

Arc 3: เจาะลึก AWS EKS และวิถีแห่ง GitOps ด้วย Argo CD (บทที่ 7-9)

เนื้อหา: เมื่อระบบเริ่มใหญ่ขึ้น อาร์เทอร์ต้องจัดการไฟล์ Deployment ที่ซับซ้อนขึ้น

ปัญหาที่แก้: เรียนรู้เรื่องการทำ Auto-scaling รับมือทราฟฟิกจากซิดนีย์, การแก้ปัญหา OutOfSync ใน Argo CD, และการตั้งค่า Resource Limits ไม่ให้เซิร์ฟเวอร์ล่ม

Arc 4: บทพิสูจน์มืออาชีพ (Climax - บทที่ 10+)

เนื้อหา: โปรเจกต์ใหญ่ประจำปีของออสเตรเลีย อาร์เทอร์ต้องรับผิดชอบการวาง Pipeline แบบครบวงจร (GitHub Actions + Argo CD + AWS EKS)

จุดพีค: ต้องพรีเซนต์แผนงานเป็นภาษาอังกฤษในที่ประชุมรวม และช่วยทีมกู้วิกฤตระบบล่มครั้งใหญ่จนผ่านการประเมินผลได้อย่างสวยงาม
