
บทที่ 12: ท้าชนด่านอรหันต์ CKA (ใบเซอร์ที่ไม่ให้กากบาท)

เช้าวันอังคาร อาร์เทอร์เดินเข้าออฟฟิศมาด้วยอารมณ์แจ่มใสหลังจากเมื่อเช้าทำสถิติวิ่ง 5 กิโลเมตรในสวนสาธารณะได้เร็วขึ้นกว่าเดิมหนึ่งนาที

แต่ทันทีที่เปิดอีเมลบริษัทขึ้นมาดู ข้อความด่วนจาก ‘เลียม’ ที่ส่งตรงมาจากเมลเบิร์น โดยมีชื่อของ ‘พี่กานต์’ แนบมาด้วย ก็ทำเอาแก้วกาแฟในมือของอาร์เทอร์ชะงักค้าง

หัวข้ออีเมลเขียนสั้นๆ ว่า: Sponsorship for CKA (Certified Kubernetes Administrator)

ไม่ทันที่อาร์เทอร์จะได้อ่านรายละเอียดทั้งหมด พี่กานต์ก็หมุนเก้าอี้มาหาพร้อมรอยยิ้มที่มีเลศนัย

"เห็นอีเมลจากเลียมหรือยังอาร์เทอร์?"

"กำลังเปิดอ่านเลยครับพี่กานต์..." อาร์เทอร์ไล่สายตาอ่านเนื้อหาภาษาอังกฤษในอีเมล แล้วคิ้วของเขาก็ค่อยๆ ขมวดเข้าหากัน "เลียมบอกว่า... บริษัทมีโควตาบัตรสอบฟรีราคา 395 ดอลลาร์ (ประมาณหมื่นสี่พันบาท) เหลืออยู่ 1 ใบที่จะหมดอายุสิ้นเดือนนี้ เลยอยากมอบให้อาร์เทอร์ไปสอบใบเซอร์ที่ชื่อว่า CKA... เพราะปลายปีนี้ เราต้องทำการอัปเกรดระบบ AWS EKS ครั้งใหญ่ของออสเตรเลียเหรอครับ?"

"ใช่แล้ว!" ‘ภพ’ ที่แอบฟังอยู่รีบชะโงกหน้าเข้ามาทำตาโต "พี่อาร์เทอร์! ใบเซอร์ CKA นี่มันคือด่านอรหันต์ของคนสาย DevOps เลยนะครับพี่! ตอนสอบ AWS Cert คราวก่อน พี่อาร์เทอร์แค่นั่งอ่านโจทย์แล้วกดเลือกกากบาทข้อ A, B, C, D ใช่ไหมครับ?"

"อื้อ ใช่สิภพ"

"แต่ CKA เนี่ย... ไม่มีข้อกากบาทแม้แต่ข้อเดียวครับพี่!" ภพทำเสียงเข้มเหมือนเล่าเรื่องผี "พอเข้าห้องสอบปุ๊บ เขาจะโยนหน้าจอดำมืดของ Linux มาให้เรา พร้อมกับคลัสเตอร์ Kubernetes ที่พังยับเยินอยู่ประมาณ 15-17 ข้อ แล้วสั่งให้เรา 'พิมพ์คำสั่งซ่อมให้เสร็จภายใน 2 ชั่วโมง!' ถ้าพิมพ์คำสั่งช้า หรือจำคำสั่งไม่ได้ ก็คือตายคาห้องสอบเลยครับ!"

อาร์เทอร์กลืนน้ำลายเอื้อมใหญ่ ข้อสอบปฏิบัติล้วนๆ... ให้พิมพ์คำสั่งซ่อมระบบจริงภายในเวลาสองชั่วโมงเนี่ยนะ?!

แค่คิดภาพว่าตัวเองต้องนั่งจ้องหน้าจอดำๆ ที่มีเคอร์เซอร์กะพริบปริบๆ โดยไม่มีตัวเลือกให้เดา แถมต้องอ่านโจทย์ภาษาอังกฤษแล้วลงมือแก้ระบบเครือข่าย ระบบเก็บข้อมูล และกู้คืนเซิร์ฟเวอร์ที่ตายแข่งกับเวลา มือของอาร์เทอร์ก็เริ่มเย็นเฉียบขึ้นมาทันที

"ยากขนาดนั้นเลยเหรอครับพี่กานต์..." อาร์เทอร์หันไปถามพี่เลี้ยงเสียงแผ่ว "ตอนนี้ผมเพิ่งจะใช้เป็นแค่คำสั่งดูพอด (kubectl get pods) กับดูบันทึก (kubectl logs) เองนะครับ ถ้าต้องไปซ่อมคลัสเตอร์ที่พังลึกๆ ผมกลัวจะทำโควตาหมื่นสี่ของบริษัทเสียเปล่าๆ"

"เพราะอาร์เทอร์ยังรู้แค่นั้นไง เลียมกับพี่ถึงอยากให้สอบใบนี้" พี่กานต์วางมือบนไหล่รุ่นน้องวัยสามสิบด้วยแววตาเชื่อมั่น

"ฟังพี่นะอาร์เทอร์ การเป็นแค่ 'ผู้ใช้งาน' Kubernetes กับการเป็น 'ผู้ดูแลระบบระดับลึก (Administrator)' มันต่างกันเยอะ... เวลาปกติที่เราใช้ AWS EKS ทาง AWS เขาดูแลสมองกลเบื้องหลังให้เราก็จริง แต่วันไหนที่โหนดเซิร์ฟเวอร์ที่ซิดนีย์เกิดค้างขึ้นมา หรือต้องอัปเกรดระบบใหญ่โดยห้ามให้เว็บล่ม คนที่จะแก้ปัญหานั้นได้ต้องเข้าใจไส้ในของ Kubernetes อย่างแท้จริง และใบเซอร์ CKA นี่แหละที่จะเปลี่ยนอาร์เทอร์จากระดับเริ่มต้น ให้กลายเป็นระดับตัวจริงที่บริษัทไหนก็อยากได้ตัว!"

พี่กานต์เปิดลิ้นชักโต๊ะทำงาน หยิบสมุดบันทึกเล่มเล็กที่ปกขาดวิ่นเพราะผ่านการใช้งานมาอย่างโชกโชน ยื่นส่งให้อาร์เทอร์

"นี่คือสมุดรวมคีย์ลัดและเทคนิคตอนที่พี่สอบ CKA เมื่อสองปีก่อน... ในสนามสอบ CKA เขาอนุญาตให้เราเปิดเว็บคู่มือ (Kubernetes Documentation) ดูได้ระหว่างสอบนะ แต่ถ้าใครมัวแต่ไปค้นหาทุกอย่างในคู่มือ เวลาสองชั่วโมงไม่มีทางพอแน่นอน สิ่งที่อาร์เทอร์ต้องฝึกตั้งแต่วันนี้คือ 'ความเร็วของนิ้วมือ' และ 'สัญชาตญาณการซ่อมระบบ'"

อาร์เทอร์รับสมุดเล่มนั้นมาด้วยสองมือ เขามองเห็นรอยปากกาที่พี่กานต์เคยจดไว้สมัยก่อน แล้วความฮึกเหิมในใจก็ค่อยๆ ลุกโชนขึ้นมาอีกครั้ง

ตอนสอบ AWS เขาก็เคยคิดว่าตัวเองทำไม่ได้ แต่สุดท้ายเขาก็ผ่านมาได้เพราะการฝึกฝน... ครั้งนี้ก็เหมือนกัน!

และเหมือนสวรรค์ต้องการให้เขาได้เริ่มฝึกวิชาตั้งแต่วันแรก...

เวลา 14:20 น. (หกโมงเย็นที่ซิดนีย์)

เสียงแจ้งเตือนสีเหลืองเด้งขึ้นมาบนหน้าจอมอนิเตอร์ของระบบ AWS EKS ฝั่งออสเตรเลีย!

คราวนี้ไม่ใช่พอดตัวเล็กๆ ที่พัง... แต่เป็น "เครื่องเซิร์ฟเวอร์หลัก (Worker Node)" เครื่องที่ 3 จากทั้งหมด 5 เครื่องในคลัสเตอร์ซิดนีย์ ที่กำลังส่งสัญญาณเตือนว่าฮาร์ดแวร์ของ AWS มีปัญหา และกำลังจะดับตัวเองลงในอีก 30 นาที!

บนเซิร์ฟเวอร์เครื่องที่ 3 นั้น มีพอดสำคัญของระบบจ่ายเงินและระบบตะกร้าสินค้ารันอยู่รวมกันถึง 25 ตัว ถ้าปล่อยให้เครื่องดับไปเฉยๆ พอดทั้ง 25 ตัวจะขาดใจตายพร้อมกัน และลูกค้าที่กำลังจ่ายเงินอยู่ในวินาทีนั้นจะหลุดออกจากระบบทันที!

"อาร์เทอร์!" พี่กานต์ชี้ไปที่หน้าจอด้วยแววตาเป็นประกาย "โจทย์ข้อที่ 1 ของข้อสอบ CKA มาเสิร์ฟถึงโต๊ะแล้ว... 'เมื่อโหนดเซิร์ฟเวอร์กำลังจะตาย จงอพยพประชากรพอดทั้งหมดออกจากตึกอย่างปลอดภัย และแปะป้ายห้ามคนใหม่เข้าตึกเด็ดขาด!'"

"อพยพพอดออกจากโหนดเหรอครับ?!" อาร์เทอร์รีบเปิดสมุดคัมภีร์ของพี่กานต์ไปที่หน้าแรกทันที

สายตาของเขาเจอกับคำสั่งสำคัญสองคำที่ถูกขีดเส้นใต้ด้วยปากกาแดง: cordon (กั้นเขตห้ามเข้า) และ drain (ระบายคนออก)!

"พี่กานต์ครับ ผมเจอคำสั่งแล้ว!" อาร์เทอร์หันไปบอกอย่างตื่นเต้น มือเตรียมพร้อมอยู่บนคีย์บอร์ด "ขั้นแรก ผมต้องใช้คำสั่ง kubectl cordon เพื่อกั้นเขตไม่ให้พอดตัวใหม่หลงเข้าไปเกิดในเซิร์ฟเวอร์เครื่องที่ 3 ที่กำลังจะพังก่อนใช่ไหมครับ?"

"ถูกต้อง! แล้วขั้นต่อไปล่ะ?"

"ขั้นที่สองคือสั่งอพยพคนเก่าด้วยคำสั่ง kubectl drain... เอ๊ะ เดี๋ยวครับพี่กานต์ ในสมุดของพี่เขียนเตือนไว้ว่า ต้องเติมหางคำสั่งว่า --ignore-daemonsets เข้าไปด้วย เพราะอะไรเหรอครับ?"

"ถามได้ดีมาก!" พี่กานต์ยิ้มกว้าง "เพราะในเซิร์ฟเวอร์ทุกเครื่อง มันจะมีพอดพิเศษที่เป็นเหมือน 'รปภ. ประจำตึก' (DaemonSet) เช่น พอดเก็บ Log หรือพอดดูแลระบบเน็ตเวิร์ก ซึ่งพวกนี้มันผูกติดกับตัวตึก อพยพออกไม่ได้ ถ้าอาร์เทอร์ไม่เติมคำสั่งบอกให้ข้ามรปภ. พวกนี้ไป คำสั่งอพยพจะค้างและล้มเหลวทันที... ในห้องสอบ CKA คนตกม้าตายเพราะลืมพิมพ์หางคำสั่งตัวนี้กันเป็นแถบเลยล่ะ!"

อาร์เทอร์จำเทคนิคนี้ขึ้นใจทันที เขาหันกลับไปที่หน้าจอดำมืด แล้วพิมพ์คำสั่งที่เพิ่งเรียนรู้สดๆ ร้อนๆ ลงไปอย่างแม่นยำ:

kubectl drain ip-10-0-3-142.ap-southeast-2.compute.internal --ignore-daemonsets --delete-emptydir-data

ปัง!

ทันทีที่กด Enter ระบบของ AWS EKS ก็เริ่มปฏิบัติการอพยพครั้งใหญ่!

บนหน้าจอของ Argo CD แทนที่พอดทั้ง 25 ตัวในตึกที่ 3 จะถูกทุบทิ้งให้ลูกค้าหลุดออกจากระบบ... Kubernetes กลับค่อยๆ สั่งสร้างพอดชุดใหม่ขึ้นมาในตึกที่ 1 และตึกที่ 2 จนพร้อมทำงานก่อน แล้วจึงค่อยๆ บอกลาพอดตัวเก่าในตึกที่ 3 ทีละตัวๆ อย่างนุ่มนวล!

ภายในเวลาสองนาที ประชากรพอดทั้ง 25 ตัวก็ย้ายบ้านเสร็จสมบูรณ์ ตึกที่ 3 กลายเป็นตึกร้างที่ขึ้นสถานะว่า Ready,SchedulingDisabled (ห้ามเข้าใช้งาน) พร้อมให้ทาง AWS ปิดเครื่องซ่อมบำรุงได้โดยที่ลูกค้าชาวออสเตรเลียไม่รู้สึกถึงความผิดปกติแม้แต่วินาทีเดียว!

"โห... นุ่มนวลมากครับพี่กานต์ กราฟทราฟฟิกไม่กระตุกเลยแม้แต่นิดเดียว!" อาร์เทอร์มองหน้าจอด้วยความทึ่งในความฉลาดของระบบ

"นี่แหละคือเสน่ห์ของวิชา CKA ล่ะอาร์เทอร์" พี่กานต์ตบไหล่เขา "แต่เมื่อกี้ นายใช้เวลาเปิดสมุดและพิมพ์คำสั่งยาวๆ นั่นไปเกือบ 3 นาที... ในสนามสอบจริง นายมีเวลาทำข้อนี้ไม่เกิน 45 วินาทีเท่านั้น!"

พี่กานต์ชี้ไปที่นาฬิกา "ตั้งแต่วันนี้เป็นต้นไป ช่วงพักเที่ยงครึ่งชั่วโมง พี่กับภพจะจำลองคลัสเตอร์พังๆ มาให้อาร์เทอร์ซ้อมมือวันละ 3 ข้อ และห้ามพิมพ์คำว่า kubectl เต็มๆ อีกต่อไป... ไปหัดตั้งคีย์ลัดให้เหลือแค่ตัว k ตัวเดียวซะ การฝึกนรกสำหรับด่านอรหันต์ CKA เริ่มขึ้นแล้ว!"

อาร์เทอร์ก้มมองนิ้วมือทั้งสิบของตัวเองบนคีย์บอร์ด หัวใจของคุณพ่อวัยสามสิบสูบฉีดด้วยความตื่นเต้น

จากคนที่เคยพิมพ์คำสั่งไปดูโพยไป... เขากำลังจะเข้าสู่โหมดฝึกวิชา "กระบี่มือไว" เพื่อก้าวขึ้นเป็นจอมยุทธ์ Kubernetes ตัวจริง!
