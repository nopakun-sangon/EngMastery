บทที่ 9: คืนวันเสาร์กับเขาวงกตไร้สาย

เสียงดินสอสีไม้ขูดไปบนกระดาษดังสวบสาบ สลับกับเสียงคลิกเมาส์เป็นจังหวะในห้องนั่งเล่นเล็กๆ ยามบ่ายวันเสาร์

บนโต๊ะญี่ปุ่นตัวเตี้ย ‘น้องออกัส’ กำลังนอนคว่ำหน้าวาดรูปหุ่นยนต์ยักษ์พ่นไฟด้วยความตั้งใจ ส่วนบนโต๊ะกินข้าวข้างๆ กัน ‘อาร์เทอร์’ กำลังนั่งกุมขมับจ้องหน้าจอโน้ตบุ๊กที่เปิดผลคะแนนข้อสอบจำลอง (Practice Exam) ชุดที่สองของ AWS

ตัวเลขสีแดงหราปรากฏอยู่กลางหน้าจอ: Score: 58% (FAIL - Passing score is 72%)

"ห้าสิบแปดเปอร์เซ็นต์..." อาร์เทอร์พึมพำเสียงแผ่ว ถอนหายใจยาวจนไหล่ลู่

แพรเดินถือจานแอปเปิลหั่นชิ้นเล็กๆ มาวางให้ลูกชายและสามี เธอมองเห็นสีหน้าเคร่งเครียดของอาร์เทอร์จึงเอื้อมมือมานวดบ่าให้เขาเบาๆ "ติดตรงเรื่องไหนหรือเปล่าคะคุณ เห็นนั่งขมวดคิ้วมาตั้งแต่เช้าแล้ว"

"เรื่อง Network น่ะแพร..." อาร์เทอร์เอนศีรษะพิงมือภรรยาอย่างอ้อนๆ "ตอนเป็นโปรแกรมเมอร์สมัยก่อน พี่แค่เขียนโค้ดให้มันทำงานได้ก็จบ เรื่องการวางสายแลน ตั้งค่าเราว์เตอร์ หรือไฟร์วอลล์ จะมีทีมดูแลระบบเขาทำให้หมด พอมาในข้อสอบ AWS มันเอาเรื่องพวกนี้ไปไว้บนอากาศ (Cloud) หมดเลย ทั้ง VPC, Subnet, Route Table, NAT Gateway... พี่อ่านโจทย์ภาษาอังกฤษยาวๆ แล้วนึกภาพไม่ออกว่าข้อมูลมันวิ่งไปติดอยู่ตรงไหน"

"ปะป๊าวาดรูปสิครับ!"

จู่ๆ น้องออกัสก็เงยหน้าขึ้นมาจากสมุดวาดเขียน ชูสีเทียนแท่งสีน้ำเงินให้พ่อ "คุณครูบอกว่า ถ้าคิดไม่ออก ให้วาดรูปออกมาครับ!"

อาร์เทอร์ชะงักไปนิดหนึ่ง มองหน้าลูกชายวัยหกขวบแล้วคลี่ยิ้มออกมา "จริงของออกัสแฮะ... ขอบคุณครับลูกพี่!"

คุณพ่อลูกหนึ่งคว้าสมุดสเก็ตช์ภาพของลูกชายมาเปิดหน้าว่าง พร้อมกับยืมสีเทียนมาสี่ห้าแท่ง เขาเลิกอ่านตัวหนังสือภาษาอังกฤษที่น่าเวียนหัวชั่วคราว แล้วเปิดคลิปติวของอาจารย์ฝรั่งขึ้นมาดูใหม่ โดยวาดรูปเปรียบเทียบตามไปด้วย:

เขาวาดรั้วบ้านขนาดใหญ่ด้วยสีดำ แล้วเขียนกำกับว่า VPC (หมู่บ้านส่วนตัวบนคลาวด์)

ข้างในรั้วบ้าน เขาวาดโซนสนามหญ้าหน้าบ้านด้วยสีเขียวที่ใครเดินผ่านไปมาก็มองเห็นได้ เรียกว่า Public Subnet (โซนสาธารณะ)

และวาดห้องนอนด้านในสุดที่ปิดมิดชิดด้วยสีน้ำเงิน ห้ามคนนอกเข้าเด็ดขาด เรียกว่า Private Subnet (โซนปลอดภัยที่พอด AWS EKS และฐานข้อมูลอาศัยอยู่)

"อ๋อ... เพราะพอดของเรามันอยู่ในห้องนอนปิดตาย (Private Subnet) เวลาคนข้างนอกจะติดต่อเข้ามา เลยต้องผ่านประตูหน้าบ้านที่ชื่อว่า Load Balancer... แต่เวลาพอดในห้องนอนอยากจะแอบสั่งของจากอินเทอร์เน็ตข้างนอก มันออกไปตรงๆ ไม่ได้ เลยต้องฝากคนรับใช้ที่ยืนอยู่หน้าบ้านที่ชื่อว่า NAT Gateway เป็นคนออกไปรับของแทน!"

เมื่อเปลี่ยนคำศัพท์เทคนิคให้กลายเป็นแผนผังบ้านด้วยสีเทียนของลูกชาย ภาพในหัวของอาร์เทอร์ก็สว่างวาบขึ้นมาทันที เขานั่งวาดรูปประตูรั้วและยามเฝ้าประตูอย่าง Security Group (ยามเฝ้าหน้าตัวพอด) และ Network ACL (ยามเฝ้าหน้าโซนหมู่บ้าน) จนเต็มหน้ากระดาษ

คืนวันเสาร์และวันอาทิตย์นั้น อาร์เทอร์ทำข้อสอบจำลองซ้ำอีกสามชุด คะแนนของเขาค่อยๆ ขยับจาก 58% เป็น 68%... และแตะ 78% ในคืนวันอาทิตย์!

เช้าวันจันทร์ เวลา 10:45 น. (เกือบบ่ายสามโมงที่เมลเบิร์น)

บรรยากาศในออฟฟิศวันนี้ดูคึกคักเป็นพิเศษ เพราะโปรเจกต์ใหม่ของฝั่งออสเตรเลียกำลังจะเชื่อมต่อระบบตรวจสอบเครดิตลูกค้าเข้ากับบริษัทธนาคารยักษ์ใหญ่แห่งหนึ่งของซิดนีย์

แต่แล้ว เสียงถอนหายใจเฮือกใหญ่ของ ‘ราจ’ และ ‘พี่กานต์’ ก็ดังขึ้นพร้อมกันที่โต๊ะข้างๆ

"ติดอะไรกันเหรอครับพี่กานต์?" อาร์เทอร์ที่เพิ่งเคลียร์งานส่งโค้ดผ่าน GitHub Actions เสร็จ ชะโงกหน้าเข้าไปถาม

"งานหินเลยล่ะอาร์เทอร์" พี่กานต์ชี้ไปที่หน้าจอที่มีแผนผังโครงสร้าง AWS เปิดอยู่คู่กับหน้าต่างแชทของ ‘โคลอี้’ และ ‘เอเลน่า’ (หัวหน้าทีมสีเขียว)

"คืออย่างนี้... โคลอี้เพิ่งเอาพอดตัวใหม่ชื่อ credit-checker ขึ้นไปรันบน AWS EKS โดยใช้ Argo CD ของเรา พอดตัวนี้ต้องยิงข้อมูลออกไปถามเซิร์ฟเวอร์ของธนาคารที่ซิดนีย์ผ่านอินเทอร์เน็ต แต่ปรากฏว่าพอยิงออกไปปุ๊บ มันค้างเติ่งจนหมดเวลา Connection Timed Out ตลอดเลย"

ราจส่ายหัวไปมาด้วยความมึนงง "I checked the Security Group of our EKS nodes, and outbound traffic is open to everywhere (0.0.0.0/0). I also checked the Route Table, and the Private Subnet routes traffic to our NAT Gateway properly. Even the bank confirmed they already whitelisted our Elastic IP! It makes no sense why the connection is timing out!"(ผมเช็กยามเฝ้าหน้าเครื่องเซิร์ฟเวอร์แล้ว ก็เปิดให้ออกได้ทุกที่ เช็กป้ายบอกทางแล้ว โซนห้องนอนก็ชี้ไปหาคนรับใช้ NAT Gateway ถูกต้อง แถมฝั่งธนาคารก็ยืนยันว่าอนุญาตเลข IP ของเราแล้วด้วย! มันไม่มีเหตุผลเลยว่าทำไมเชื่อมต่อไม่ได้!)

ในห้องประชุมย่อยออนไลน์ที่เปิดค้างไว้ เอเลน่าจากทีมสีเขียวก็ขมวดคิ้วแน่น "Don't look at me, Raj. Green Team didn't block the bank's IP on the firewall." (อย่ามองฉันแบบนั้นค่ะราจ ทีมสีเขียวไม่ได้บล็อก IP ของธนาคารที่ไฟร์วอลล์เลยนะ)

อาร์เทอร์เลื่อนเก้าอี้เข้าไปใกล้ ภาพวาดสีเทียนรูป "หมู่บ้าน VPC" ที่เขานั่งวาดกับลูกชายเมื่อวันเสาร์ซ้อนทับขึ้นมาบนหน้าจอทันที

เขาไล่สายตาดูตามเส้นทางการวิ่งของข้อมูลที่ราจเปิดไว้:

พอดใน Private Subnet วิ่งออกประตูผ่านยาม Security Group -> ผ่าน

วิ่งตามป้ายบอกทาง Route Table ไปหาคนรับใช้ NAT Gateway ที่ยืนอยู่ใน Public Subnet -> ผ่าน

คนรับใช้ NAT Gateway วิ่งออกไปหาธนาคารที่อินเทอร์เน็ต แล้วธนาคารก็ส่งคำตอบกลับมา... แต่คำตอบกลับมาไม่ถึงพอด!

เดี๋ยวนะ... ขาไปออกไปได้ แต่ขากลับเข้าไม่ได้ จนเกิดอาการรอเก้อ (Connection Timed Out)?!

"พี่กานต์ครับ พี่ราจครับ..." อาร์เทอร์เอ่ยขึ้นด้วยน้ำเสียงตื่นเต้น "ในข้อสอบ AWS ที่ผมเพิ่งทำเมื่อคืน มันมีโจทย์หลอกข้อหนึ่งที่อาการแบบนี้เป๊ะเลยครับ!"

ทั้งพี่กานต์ ราจ และภพ หันมามองอาร์เทอร์เป็นตาเดียว

"คือยามเฝ้าประตูเนี่ย มันมี 2 ระดับใช่ไหมครับ..." อาร์เทอร์ชี้ไปที่หน้าจอ "พี่ราจเช็ก Security Group ไปแล้ว ซึ่งเจ้าตัวนี้มันฉลาด (Stateful) ถ้ามันเห็นเราเดินออกไป มันจะจำหน้าไว้ แล้วตอนขากลับมันจะเปิดประตูให้เข้าเองโดยอัตโนมัติ... แต่ยามอีกคนที่เฝ้าอยู่หน้าโซนหมู่บ้านที่ชื่อว่า Network ACL (NACL) เนี่ย มันความจำสั้น (Stateless)! ขาออกอนุญาตให้ออก แต่ถ้าขากลับไม่ได้เขียนกฎเปิดพอร์ตชั่วคราว (Ephemeral Ports) รอรับไว้... มันจะกั้นไม่ให้ข้อมูลจากธนาคารเดินกลับเข้ามาหาเราครับ!"

ราจเบิกตากว้างจนตาแทบถลน "Wait a second... Ephemeral ports on Network ACL?! Did someone touch the NACL of our Public Subnet?!"(เดี๋ยวก่อนนะ... พอร์ตชั่วคราวบน NACL เหรอ?! มีใครไปแตะต้องตั้งค่า NACL ของโซนหน้าบ้านเราหรือเปล่า?!)

เอเลน่าที่ฟังอยู่ในสายรีบคลิกเมาส์รัวๆ ที่เครื่องของตัวเองทันที เสียงคลิกเงียบไปห้าวินาที ก่อนที่สาวสายเฮี้ยบจะอุทานออกมาเบาๆ

"Oh... Last week during the DDoS drill, Marcus asked my junior engineer to restrict inbound ports on the Public Subnet NACL to only port 443 (HTTPS). He forgot to allow Ephemeral Ports (1024-65535) for return traffic from the NAT Gateway!"(โอ้... สัปดาห์ก่อนตอนซ้อมรับมือการโจมตี มาร์คัสสั่งให้น้องในทีมของฉันจำกัดพอร์ตขาเข้าของโซนหน้าบ้านให้รับแค่พอร์ต 443 อย่างเดียว เขาลืมเปิดพอร์ตชั่วคราว 1024-65535 สำหรับรับข้อมูลขากลับของ NAT Gateway ค่ะ!)

"โป๊ะเชะเลย!!" พี่กานต์ตบโต๊ะดังป้าบ ยิ้มกว้างจนตาหยี "เพราะแบบนี้นี่เอง! พอดของเราส่งคำขอออกไปหาธนาคารที่พอร์ต 443 ได้ แต่พอธนาคารส่งคำตอบกลับมาที่พอร์ตสุ่มชั่วคราวของ NAT Gateway ยามหน้าหมู่บ้านดันบล็อกไว้เพราะเห็นไม่ใช่เลข 443 ข้อมูลเลยค้างเติ่งอยู่หน้าประตูบ้าน!"

"I am updating the Network ACL via Terraform right now... Done! Applied!" เอเลน่าสั่งแก้กฎผ่านโค้ดทันที

"ภพ ลองกดสั่งเทสต์ยิงข้อมูลจากพอดไปหาธนาคารอีกรอบซิ!" พี่กานต์สั่ง

ภพกดปุ่มรันคำสั่งทดสอบบนหน้าจอดำมืด... เพียงเสี้ยววินาที ข้อความที่เคยค้างเติ่งจนหมดเวลา ก็เด้งผลลัพธ์กลับมาเป็นตัวอักษรสีเขียวสดใส:

HTTP/1.1 200 OK - {"status": "Credit Verified", "bank_ref": "SYD-99812"}

"เชื่อมต่อธนาคารซิดนีย์สำเร็จแล้วครับ!!" ภพร้องเฮลั่นโต๊ะ

"Unbelievable, Arthur!" ราจหันมาตบไหล่อาร์เทอร์รัวๆ ด้วยความทึ่ง "Network ACL stateless ephemeral ports is one of the trickiest things to debug in AWS because nobody looks at NACLs anymore! How did you figure that out so quickly?!"(เหลือเชื่อมากอาร์เทอร์! เรื่องพอร์ตขากลับของ NACL นี่เป็นหนึ่งในเรื่องที่หาสาเหตุยากที่สุดใน AWS เลยนะเพราะปกติไม่มีใครเข้าไปดูมันแล้ว! คุณคิดออกเร็วขนาดนั้นได้ยังไงเนี่ย?!)

อาร์เทอร์ยิ้มเขินๆ เกาแก้มตัวเองเบาๆ ก่อนจะตอบเป็นภาษาอังกฤษที่เรียงประโยคง่ายๆ แต่ทำเอาทุกคนในห้องประชุมออนไลน์หัวเราะออกมาพร้อมกัน

"My six-year-old son told me to draw a house with crayons yesterday... so I remembered the gatekeeper rules."
(ลูกชายวัยหกขวบของผมบอกให้ผมวาดรูปบ้านด้วยสีเทียนเมื่อวานนี้ครับ... ผมก็เลยจำกฎของยามเฝ้าประตูได้)

แม้แต่เอเลน่าผู้แสนเย็นชาก็ยังหลุดเสียงหัวเราะเบาๆ ออกมาทางไมโครโฟน "Please thank your son for the Green Team, Arthur. And if you know VPC networking at this level... go book your AWS exam right now. You are more than ready."(ฝากขอบคุณลูกชายของคุณแทนทีมสีเขียวด้วยนะคะอาร์เทอร์ แล้วถ้าคุณเข้าใจระบบเครือข่าย VPC ลึกซึ้งระดับนี้แล้วล่ะก็... ไปกดจองวันสอบ AWS เดี๋ยวนี้เลยค่ะ คุณพร้อมยิ่งกว่าพร้อมแล้ว)

พี่กานต์พยักหน้าเห็นด้วยทันที "จริงอย่างที่เอเลน่าพูดเลยอาร์เทอร์ ความรู้แน่นจนเอามาแก้บั๊กยากสุดหินของ AWS ได้ขนาดนี้ ไม่ต้องรอถึงสิ้นเดือนแล้ว จองสอบวันเสาร์นี้เลยน้องชาย เดี๋ยวพี่อนุมัติงบค่าสอบให้เดี๋ยวนี้!"

อาร์เทอร์มองหน้าพี่กานต์ ราจ และภพ ที่พยักหน้าเชียร์เขาอย่างเต็มที่ หัวใจของชายวัยสามสิบเต้นแรงด้วยความฮึกเหิม

เขาเปิดหน้าเว็บจองสอบของ AWS ขึ้นมา คลิกเลือกศูนย์สอบใจกลางกรุงเทพฯ ในเช้าวันเสาร์ที่จะถึงนี้ แล้วกดปุ่ม Confirm Booking ลงไปอย่างเด็ดขาด!

อีกเพียงห้าวันข้างหน้า... เขาจะต้องเดินเข้าสู่ห้องสอบจริงที่มีคำถามภาษาอังกฤษ 65 ข้อรออยู่ เพื่อพิสูจน์ว่าคนต้นทุนต่ำอย่างเขาก็สามารถคว้าใบรับรองระดับโลกมาครองได้!
