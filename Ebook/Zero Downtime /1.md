บทที่ 1: เช้าวันจันทร์และกำแพงที่มองไม่เห็น

"ปะป๊า วันนี้กลับมากินข้าวเย็นทันไหมครับ? ครูให้การบ้านวาดรูปครอบครัวด้วยนะ"

เสียงเจื้อยแจ้วของ ‘ออกัส’ ลูกชายวัยหกขวบในชุดนักเรียนอนุบาลเอ่ยถาม ขณะที่ ‘อาร์เทอร์’ กำลังก้มลงผูกเชือกรองเท้าผ้าใบให้ลูกที่หน้าประตูบ้าน

"ทันสิครับลูก ห้าโมงครึ่งปะป๊าก็รีบซิ่งรถกลับมาหาออกัสแล้ว" อาร์เทอร์ยิ้มกว้าง ยื่นมือไปขยี้หัวลูกชายเบาๆ ก่อนจะเงยหน้าสบตากับ ‘แพร’ ภรรยาที่ยืนถือกล่องข้าวกลางวันส่งให้

"สู้ๆ นะคุณ วันแรกในทีมใหม่ใช่ไหม ไม่ต้องกดดันตัวเองเกินไปนะ" แพรบีบมือเขาเบาๆ

อาร์เทอร์พยักหน้ารับคำอวยพรนั้นไว้ แม้ในใจจะรู้ดีว่าคำว่า ‘ไม่กดดัน’ นั้นแทบเป็นไปไม่ได้เลยสำหรับชายวัยสามสิบปีที่จบจากมหาวิทยาลัยโนเนมอย่างเขา

ตลอดเจ็ดปีที่ผ่านมา อาร์เทอร์เป็นแค่โปรแกรมเมอร์ธรรมดาๆ ในบริษัทไทย เขียนโค้ดแบบเก่าๆ โยนไฟล์ขึ้นเซิร์ฟเวอร์ด้วยวิธีเดิมๆ ไม่ต้องใช้ภาษาอังกฤษ ไม่ต้องรู้จักเทคโนโลยีล้ำสมัย ชีวิตของเขาเรียบง่ายและปลอดภัย... จนกระทั่งเมื่อเดือนก่อน บริษัทถูกกลุ่มทุนเทคโนโลยีข้ามชาติเข้าซื้อกิจการ

โครงสร้างบริษัทถูกรื้อใหม่ทั้งหมด แผนกเดิมของอาร์เทอร์ถูกยุบ คนที่ปรับตัวไม่ได้ถูกเชิญออกพร้อมเงินชดเชย ส่วนอาร์เทอร์ที่ยังมีภาระผ่อนบ้านและค่าเทอมลูกชั้นประถมที่กำลังจะมาถึง ไม่มีทางเลือกอื่นนอกจากยอมรับคำสั่งย้ายมาอยู่ในแผนกที่เขาไม่คุ้นเคยที่สุด... ‘DevOps’

และเช้านี้ คือวันแรกของเขาในฐานะสมาชิกของ Blue Team ทีมที่ดูแลระบบหลักของประเทศออสเตรเลีย

08:45 น. ออฟฟิศชั้น 22 ย่านใจกลางเมือง

บรรยากาศในโซนของทีม DevOps ทั้งสิบห้าคนดูคึกคักและทันสมัยจนอาร์เทอร์รู้สึกเกร็ง บนโต๊ะทำงานทุกตัวมีจอมอนิเตอร์ขนาดใหญ่สองจอวางเรียงกัน หน้าจอเต็มไปด้วยกราฟสีสันสดใสและหน้าต่างสีดำที่มีตัวหนังสือภาษาอังกฤษวิ่งรัวๆ

"อาร์เทอร์! มาเช้าเหมือนกันนะเนี่ย กินกาแฟยัง?"

เสียงทักทายอย่างเป็นกันเองดังขึ้นจากโต๊ะข้างๆ ‘พี่กานต์’ หัวหน้าทีม Blue ฝั่งไทยวัยสามสิบสองปี ยื่นแก้วกาแฟดริปส่งให้ ถัดไปอีกโต๊ะคือ ‘ภพ’ หนุ่มรุ่นน้องวัยยี่สิบหกที่กำลังนั่งพิมพ์คีย์บอร์ดไฟ RGB เสียงดังต็อกแต๊กอย่างเมามัน

"เรียบร้อยแล้วครับพี่กานต์ ขอบคุณครับ" อาร์เทอร์รับแก้วกาแฟมาวาง มือที่จับเมาส์ชื้นไปด้วยเหงื่อ "เอ่อ... พี่กานต์ครับ วันนี้ผมต้องเริ่มจากดูตรงไหนก่อนดีครับ พอดีผมยังงงๆ กับระบบที่พี่ส่งลิงก์ให้เมื่อวันศุกร์อยู่เลย"

"ไม่ต้องรีบๆ เดี๋ยวเก้าโมงตรงเข้า Daily Standup กับฝั่งออสเตรเลียก่อน วันนี้ ‘เลียม’ เดี๋ยวเขาน่าจะจ่ายงานง่ายๆ ให้เราลองจับดู" พี่กานต์ตบไหล่เขาเบาๆ อย่างเข้าใจ "ไม่ต้องเกร็งเรื่องภาษานะ ฟังไม่ทันเดี๋ยวพี่ช่วยสรุปให้"

คำว่า ประชุมกับฝั่งออสเตรเลีย ทำเอาท้องไส้ของอาร์เทอร์ปั่นป่วนขึ้นมาทันที

เก้าโมงตรงเป๊ะ หน้าจอโปรแกรมประชุมออนไลน์ก็เด้งขึ้นมา สมาชิกทีม Blue ทั้งห้าคนเข้ามาอยู่ในห้องครบ ใบหน้าของ ‘เลียม’ หัวหน้าใหญ่ชาวออสเตรเลียโผล่ขึ้นมาพร้อมรอยยิ้มกว้าง และ ‘โคลอี้’ สาวฝรั่งตาน้ำข้าวที่เป็น Developer ฝั่งซิดนีย์

"G'day mates! Hope everyone had a smashing weekend. Welcome aboard, Arthur! How's it going?"

เสียงของเลียมดังมาจากลำโพงหูฟัง มันเป็นภาษาอังกฤษสำเนียงออสซี่ที่ทั้งเร็วและรวบคำจนอาร์เทอร์จับใจความได้แค่คำว่า ‘Weekend’ กับชื่อของตัวเอง เขานั่งตัวแข็งทื่อ สมองพยายามแปลประโยคนั้นอย่างหนักหน่วง จนเกิดความเงียบขึ้นในห้องประชุมไปสามวินาที

พี่กานต์แอบสะกิดแขนเขาเบาๆ แล้วกระซิบ "เขาทักทายเฉยๆ ถอดไมค์แล้วตอบว่า I'm good, thank you ก็พอ"

"อะ... เอ่อ I'm good. Thank you, Liam." อาร์เทอร์กดเปิดไมค์แล้วตอบออกไปด้วยเสียงที่สั่นนิดๆ รู้สึกร้อนวูบที่ใบหน้าเหมือนตัวเองกลับไปเป็นเด็กประถมที่ถูกครูฝรั่งเรียกถามหน้าชั้นเรียนไม่มีผิด

หลังจากนั้น การประชุมก็ดำเนินไปอย่างรวดเร็ว โคลอี้กับภพคุยกันเรื่องการอัปเดตระบบ ส่วนราจ หนุ่มอินเดียที่นั่งอยู่โต๊ะถัดไปก็รายงานเรื่องฐานข้อมูล ทุกคนพูดศัพท์เทคนิคที่อาร์เทอร์ไม่เคยได้ยินมาก่อนในชีวิตผสมไปกับภาษาอังกฤษที่ไหลลื่น

EKS Cluster... Pod Eviction... Jenkins Pipeline ค้าง... ต้องย้ายไป GitHub Actions... แล้วให้ Argo CD ซิงค์ใหม่...

อาร์เทอร์นั่งถือปากกาค้างไว้เหนือสมุดโน้ต เขาจดตามได้แค่ตัวอักษรย่อแบบผิดๆ ถูกๆ ความรู้สึกไร้ค่าค่อยๆ กัดกินหัวใจของคนวัยสามสิบที่เคยคิดว่าตัวเองเขียนโปรแกรมเก่งมาตลอด นี่เขาหลุดเข้ามาอยู่ในโลกใบไหนกันแน่?

"Alright, Arthur..." เสียงของเลียมดึงสติของอาร์เทอร์กลับมาอีกครั้ง "For your first task, Chloe's team just pushed a small config change for the payment service. Can you check the Jenkins build and make sure Argo CD deploys the new pod to our Sydney AWS EKS staging environment? Karn will guide you through it. No worries, take your time!"

อาร์เทอร์ได้ยินแค่คำว่า Chloe, Jenkins, Argo CD, AWS EKS... แต่ต้องทำยังไงต่อ สมองเขาขาวโพลนไปหมด

"Yes... Okay, Liam." เขาตอบรับไปตามสัญชาตญาณเพื่อให้พ้นสถานการณ์ตรงหน้าไปก่อน

พอจบการประชุม อาร์เทอร์ถอดหูฟังออกแล้วถอนหายใจยาวเหยียด เอนหลังพิงพนักเก้าอี้อย่างคนหมดแรง สายตาเหลือบไปเห็นรูปถ่ายโพลารอยด์ใบเล็กที่เขาเพิ่งเอามาแปะไว้ใต้จอมอนิเตอร์เมื่อเช้า... รูปของน้องออกัสที่กำลังยิ้มแฉ่งโชว์ฟันหลอคู่กับแพร

จะมายอมแพ้ตั้งแต่วันแรกไม่ได้สิวะไอ้อาร์เทอร์... ถ้าแกไม่รอดที่นี่ แล้วลูกจะเรียนที่ไหน

อาร์เทอร์สูดหายใจเข้าลึกๆ หันเก้าอี้ไปหาพี่กานต์ทันทีโดยไม่ปล่อยให้ความอายมาขวางกั้น

"พี่กานต์ครับ... ผมสารภาพตรงๆ เลย เมื่อกี้ผมฟังเลียมออกแค่สามสิบเปอร์เซ็นต์ แถมไอ้เจ้า Jenkins, Argo CD กับ AWS EKS ที่ว่าเนี่ย ผมไม่เคยจับมาก่อนเลยครับ พี่ช่วยชี้เป้าให้ผมหน่อยได้ไหมครับว่าผมต้องเริ่มอ่านจากตรงไหนก่อน"

พี่กานต์หันมามองอาร์เทอร์ แล้วคลี่ยิ้มมุมปากอย่างพอใจ

"พี่ชอบคนตรงๆ แบบนี้แหละอาร์เทอร์ ไม่รู้ก็บอกว่าไม่รู้ ดีกว่ามั่วแล้วระบบที่ซิดนีย์พัง" พี่กานต์เลื่อนเก้าอี้เข้ามาใกล้ แล้วชี้ไปที่หน้าจอของอาร์เทอร์ที่มีรูปคุณลุงใส่ชุดพ่อบ้าน (Jenkins) กับรูปปลาหมึกสีส้ม (Argo CD) เปิดค้างอยู่

"ฟังนะ ตอนนี้โปรเจกต์ออสเตรเลียของเรากำลังอยู่ในช่วงเปลี่ยนผ่าน สมัยก่อนเราใช้โปรแกรมคุณลุง Jenkins ตัวนี้ในการแพ็กโค้ดของโคลอี้ให้เป็นกล่องคอนเทนเนอร์... ซึ่งเดี๋ยวอนาคตเราจะโละทิ้งไปใช้ GitHub Actions แทนแล้วล่ะ แต่สำหรับงานวันนี้ อาร์เทอร์ต้องเข้าไปกดรันงานใน Jenkins ก่อน พอมันสร้างกล่องเสร็จ หน้าทีของเจ้าปลาหมึกสีส้ม Argo CD คือการดึงกล่องใบนั้น ไปวางลงบนระบบคลาวด์ที่ชื่อว่า AWS EKS ที่ซิดนีย์"

พี่กานต์เขียนคำศัพท์ 4 คำลงบนกระดาษโพสต์อิทแล้วแปะไว้ที่ขอบจอของอาร์เทอร์:

Jenkins Build

Docker Image

Argo CD Sync

AWS EKS Pod

"เช้านี้ พี่ให้เวลาเราไปทำความเข้าใจสี่คำนี้ก่อน แล้วลองกดรันงานของโคลอี้ในระบบทดสอบ (Staging) ดู ถ้ามันขึ้นสีแดงหรือติดตรงไหน... เรียกพี่กับไอ้ภพได้ตลอด ลุยเลยน้องชาย!"

อาร์เทอร์มองโพสต์อิทสีเหลืองใบนั้น ความกลัวเมื่อครู่ค่อยๆ เปลี่ยนเป็นเป้าหมายที่ชัดเจนขึ้น เขาเปิดหน้าเว็บแปลภาษาคู่กับหน้าคู่มือภาษาอังกฤษของบริษัท เตรียมสมุดโน้ตเล่มใหม่ขึ้นมาวางข้างคีย์บอร์ด

สำหรับเด็กจบใหม่อาจจะใช้เวลาทำความเข้าใจเรื่องพวกนี้แค่ครึ่งชั่วโมง แต่สำหรับคนวัยสามสิบที่เริ่มต้นจากศูนย์อย่างเขา ต่อให้ต้องใช้เวลาสองชั่วโมงและต้องเปิดดิกชันนารีทุกบรรทัด... เขาก็จะทำให้เจ้าปลาหมึกสีส้มตัวนั้นเปลี่ยนเป็นสีเขียวให้ดู!
