บทที่ 14: ผ่าตัดใหญ่กลางอากาศ และป้ายทะเบียนที่สาบสูญ

เช้าวันพฤหัสบดี บรรยากาศในโซนของทีม Blue เงียบสงบแต่แฝงไปด้วยความตึงเครียดเหมือนห้องผ่าตัดของโรงพยาบาลใหญ่

เพราะวันนี้คือวันที่ทีมจะต้องทำการ "อัปเกรดเวอร์ชันของ AWS EKS" ของระบบทดสอบใหญ่ (Staging) จากเวอร์ชัน 1.28 ไปเป็น 1.29 เพื่อเตรียมความพร้อมก่อนทำจริงบนเซิร์ฟเวอร์หลักของซิดนีย์ในสัปดาห์หน้า

"ในข้อสอบ CKA จะมีข้อนึงที่ให้เราอัปเกรดคลัสเตอร์ Kubernetes ด้วยมือผ่านคำสั่ง kubeadm" พี่กานต์พูดขึ้นขณะเปิดหน้าจอ AWS Console ขึ้นจอกลาง "แต่เวลาเราทำงานจริงบน AWS EKS ทาง AWS เขาทำปุ่มกดอัปเกรดสมองกลหลัก (Control Plane) มาให้เราง่ายๆ เลย... ทว่าความยากของจริงมันไม่ได้อยู่ที่ตอนกดปุ่มหรอกนะอาร์เทอร์"

"มันอยู่ที่ตรงไหนเหรอครับพี่กานต์?" อาร์เทอร์ถามพลางเตรียมสมุดโน้ต

"มันอยู่ที่ว่า... พอสมองกลอัปเกรดเป็นเวอร์ชันใหม่เสร็จแล้ว ใบสั่งงาน YAML เก่าๆ บางตัวที่เราเคยเขียนไว้ใน Argo CD มันอาจจะถูก 'ยกเลิกการใช้งาน (Deprecated API)' ในเวอร์ชันใหม่! เหมือนกฎหมายจราจรที่เพิ่งเปลี่ยนป้ายทะเบียนรถแบบเก่าให้ผิดกฎหมายนั่นแหละ ถ้าเราไม่ตรวจดูให้ดี พอกดอัปเกรดปุ๊บ ระบบจะพังทันที"

พี่กานต์หันไปพยักหน้าให้ภพ "ภพ ลองกดอัปเกรดคลัสเตอร์ Staging แล้วเริ่มสลับโหนดเซิร์ฟเวอร์ชุดใหม่ (Node Group) เข้ามาแทนที่ชุดเก่าได้เลย เดี๋ยวให้อาร์เทอร์เป็นคนคอยเฝ้าดูอาการของพอดทั้ง 40 เซอร์วิสผ่าน Argo CD"

"จัดไปครับพี่!"

กระบวนการผ่าตัดเปลี่ยนเครื่องยนต์กลางอากาศเริ่มต้นขึ้น AWS EKS ค่อยๆ สร้างเครื่องเซิร์ฟเวอร์เวอร์ชัน 1.29 ชุดใหม่ขึ้นมา แล้วใช้หลักการ Drain อพยพพอดจากเครื่องเก่ามายังเครื่องใหม่อย่างนุ่มนวล

อาร์เทอร์นั่งจ้องหน้าจอเจ้าปลาหมึกสีส้ม Argo CD ตาไม่กะพริบ เซอร์วิสที่ 1 ถึง 38 ย้ายบ้านสำเร็จและขึ้นสถานะสีเขียว Healthy อย่างสวยงาม

แต่แล้ว... ที่เซอร์วิสตัวที่ 39 และ 40 ซึ่งเป็นระบบเก่าแก่ที่ดูแลเรื่องการส่งอีเมลใบเสร็จ (legacy-mailer) ที่เขียนทิ้งไว้ตั้งแต่สองปีก่อน จู่ๆ ก็ขึ้นสถานะสีเหลือง SyncFailed (ซิงค์ข้อมูลล้มเหลว) พร้อมกับที่ระบบปั๊มพอดอัตโนมัติและทางเข้าเว็บของมันหายสาบสูญไปจากคลัสเตอร์!

Argo CD Error: resource HPA "autoscaling/v2beta2" is not recognized in Kubernetes v1.29. Unable to sync.

"นั่นไง มาตามนัดจริงๆ ด้วย!" พี่กานต์ชี้ไปที่ข้อความสีแดงบนจอ "อาร์เทอร์ ลองอ่านข้อความ Error นั้นแล้วบอกพี่ซิว่าเกิดอะไรขึ้น และเราจะใช้คำสั่งอะไรในวิชา CKA เพื่อหาว่าในเวอร์ชัน 1.29 นี้ เราต้องแก้ป้ายทะเบียนมันเป็นคำว่าอะไร?"

อาร์เทอร์ขมวดคิ้วอ่านข้อความภาษาอังกฤษนั้นอย่างรวดเร็ว

"มันฟ้องว่า... ระบบไม่รู้จักป้ายทะเบียน autoscaling/v2beta2 ของตัวปั๊มพอด HPA ในเวอร์ชัน 1.29 แล้วครับ เพราะมันเป็นชื่อรุ่นทดลอง (beta) สมัยเก่าที่ถูกถอดออกไปแล้ว!"

อาร์เทอร์ไม่รอช้า เขาสลับหน้าจอไปที่เทอร์มินัลสีดำ แล้วพิมพ์คำสั่งตรวจสอบทรัพยากรของคลัสเตอร์ที่เขาเพิ่งฝึกซ้อมกับภพเมื่อวานนี้ทันที:

k api-resources | grep hpa

หน้าจอดำมืดแสดงผลลัพธ์กลับมาภายในเสี้ยววินาทีว่า ปัจจุบันคำสั่ง HPA ได้รับการเลื่อนขั้นเป็นรุ่นสมบูรณ์ที่ชื่อว่า autoscaling/v2 (ตัดคำว่า beta2 ทิ้งไป) เรียบร้อยแล้ว!

"เจอแล้วครับพี่กานต์! ในเวอร์ชันใหม่ เราต้องเปลี่ยนบรรทัด apiVersion ในไฟล์แม่พิมพ์ Helm จาก autoscaling/v2beta2 ให้กลายเป็น autoscaling/v2 ครับ!"

"ยังเร็วได้อีกอาร์เทอร์!" พี่กานต์ยิ้มมุมปาก "แล้วถ้าพี่จำโครงสร้างข้างในของรุ่น v2 ไม่ได้ล่ะ ว่าต้องเคาะวรรคยังไง อาร์เทอร์จะเปิดดูคู่มือจากในหน้าจอดำนี้เลยได้ด้วยคำสั่งอะไร โดยไม่ต้องไปเปิดเว็บหาให้เสียเวลา?"

นิ้วของอาร์เทอร์พรมลงบนคีย์บอร์ดเหมือนตอบสนองโดยอัตโนมัติ:k explain hpa.spec

คำอธิบายโครงสร้างทุกบรรทัดเด้งขึ้นมาบนหน้าจอดำอย่างละเอียด อาร์เทอร์ใช้เวลาไม่ถึงสองนาทีในการเข้าไปแก้ไฟล์แม่พิมพ์ Helm Chart ส่งผ่าน GitHub Actions และให้ Argo CD ซิงค์ใหม่

ปัง! ระบบส่งอีเมลใบเสร็จกลับมาเป็นสีเขียว Healthy ทันที! การซ้อมใหญ่สำหรับการอัปเกรด AWS EKS ผ่านพ้นไปได้ด้วยดีเพราะความแม่นยำในคำสั่งพื้นฐานของอาร์เทอร์

"Mate, you're practically a walking kubectl encyclopedia now!" ราจที่นั่งดูอยู่เอ่ยชมพร้อมรอยยิ้ม "You are going to crush that CKA exam on Sunday night!"(เพื่อนยาก ตอนนี้นายแทบจะเป็นสารานุกรมคำสั่งเดินได้อยู่แล้วนะ! คืนวันอาทิตย์นี้นายจะต้องบดขยี้ข้อสอบ CKA แหลกคามือแน่นอน!)
