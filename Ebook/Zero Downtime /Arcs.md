โครงสร้างเนื้อเรื่อง (Story Arcs) ตั้งแต่ บทที่ 1 ถึง บทที่ 20 (จบซีซันแรก) โดยสอดแทรกภารกิจสำคัญอย่างการสอบ AWS Certificate และ Kubernetes (CKA / EKS) Certificate เข้าไปเป็นเงื่อนไขในการ "ผ่านโปรและปรับฐานเงินเดือน" ของอาร์เทอร์ ซึ่งจะทำให้เรื่องราวมีเป้าหมายที่ชัดเจนและลุ้นระทึกขึ้นมากครับ

Arc 1: เอาตัวรอดในโลกใบใหม่ (บทที่ 1 - 5)จุดเริ่มต้นของคุณพ่อวัย 30 ที่ต้องปรับตัวกับเครื่องมือยุคใหม่และกำแพงภาษา

บทที่ 1: เช้าวันจันทร์และกำแพงที่มองไม่เห็น — อาร์เทอร์เริ่มงานวันแรกในทีม Blue เจอการประชุมภาษาอังกฤษสำเนียงออสซี่ของเลียม และได้รับมอบหมายให้รู้จักกับ Jenkins, Argo CD และ AWS EKS โดยมีพี่กานต์คอยชี้แนะ

บทที่ 2: เจ้าปลาหมึกสีส้มกับหัวใจที่เต้นผิดจังหวะ — ลงมือ Deploy งานแรกแต่เจออาการพอดพัง (CrashLoopBackOff) อาร์เทอร์หัดไล่เช็ก Log และรวบรวมความกล้าพิมพ์แชทภาษาอังกฤษแจ้งบั๊กกับโคลอี้เป็นครั้งแรก

บทที่ 3: ลมหายใจเฮือกสุดท้ายของคุณปู่ Jenkins — เซิร์ฟเวอร์ Jenkins ดิสก์เต็มจนค้างในช่วงเวลาสำคัญ อาร์เทอร์ช่วยเคลียร์พื้นที่ดิสก์เฉพาะหน้า และได้รับโปรเจกต์แรกจากเลียมในการย้ายระบบไปใช้ GitHub Actions (GHA)

บทที่ 4: ย่อหน้ามรณะกับด่านตรวจของเอเลน่า — อาร์เทอร์งมกับการเขียนไฟล์ YAML ของ GitHub Actions และต้องผ่านด่านตรวจความปลอดภัยของเอเลน่า (Green Team) ด้วยการทำระบบยืนยันตัวตนแบบไร้รหัสผ่าน (OIDC เชื่อมกับ AWS IAM Role)

บทที่ 5: เสียงไซเรนสีแดงและศึกหนักวันศุกร์ — แคมเปญ Flash Sale ที่ซิดนีย์ทำพอดตายเพราะเมมโมรี่เต็ม (OOMKilled) อาร์เทอร์ตัดสินใจเปิดไมค์พูดภาษาอังกฤษในห้อง War Room และใช้ Pipeline ใหม่กู้วิกฤตได้ภายใน 1 นาที

Arc 2: ก้าวสู่มาตรฐานโลกและภารกิจล่าใบเซอร์ AWS (บทที่ 6 - 10)เมื่อการทำงานหน้างานเริ่มเข้าที่ บริษัทจึงยื่นเงื่อนไขการผ่านโปรด้วยการสอบใบรับรองระดับโลก

บทที่ 6: เงาของความขัดแย้งและกับดัก OutOfSync — มาร์คัส (สถาปนิกอาวุโสฝั่งซิดนีย์) แอบแก้ค่าบน Production ด้วยมือจนตีกับ Argo CD อาร์เทอร์ใช้หลักฐานจาก Log แชร์หน้าจอประจันหน้าในที่ประชุมเพื่อปกป้องระบบและทีม

บทที่ 7: กองทัพโคลนนิ่งและบิลค่าไฟที่มองไม่เห็น — ภพตั้งค่าการขยายพอดอัตโนมัติ (HPA) ผิดพลาดจนเสกพอดออกมา 100 ตัวรุมยิงฐานข้อมูล อาร์เทอร์เข้าสับคัตเอาต์หยุดระบบและแก้ไขค่าทรัพยากรได้อย่างเฉียบขาด

บทที่ 8: เงื่อนไขของการเติบโต (ภารกิจ AWS Cert) — HR และเลียมแจ้งเกณฑ์การผ่านทดลองงานและปรับเงินเดือนของบริษัทข้ามชาติ: สมาชิกทีม Blue ต้องมีใบเซอร์ AWS Certified Solutions Architect (SAA) หรือ SysOps ภายใน 1 เดือน! อาร์เทอร์เครียดเพราะข้อสอบเป็นภาษาอังกฤษล้วนและโจทย์ยาวมาก

บทที่ 9: คืนวันเสาร์กับข้อสอบจำลองร้อยข้อ — อาร์เทอร์แบ่งเวลาหลังลูกหลับมานั่งทำข้อสอบจำลอง (Practice Exams) โดยมีราจและพี่กานต์ช่วยติวเรื่องโครงสร้าง Network บน AWS (VPC, Subnet, Route Table) ที่เขาเคยอ่อนที่สุด

บทที่ 10: ห้องสอบที่เงียบงันและประตูบานแรก — วันสอบจริงที่ศูนย์สอบ อาร์เทอร์ต้องสู้กับเวลาและความกดดันในการอ่านโจทย์ภาษาอังกฤษยาวๆ เขานำประสบการณ์การแก้ปัญหาหน้างานมาวิเคราะห์ตัดช้อยส์ จนสอบผ่านคว้าใบเซอร์ AWS ใบแรกในชีวิตมาให้ลูกเมียภูมิใจได้สำเร็จ!

Arc 3: เจาะลึกสมรภูมิ Kubernetes และด่านหิน CKA / EKS (บทที่ 11 - 15)จากความรู้ระดับพื้นฐาน สู่การเป็นผู้เชี่ยวชาญการจัดการคอนเทนเนอร์และบททดสอบแบบลงมือทำจริง

บทที่ 11: ปริศนาเขาวงกต Network (ความรู้จากใบเซอร์ช่วยชีวิต) — เกิดปัญหาเซอร์วิสที่ซิดนีย์คุยกับระบบจ่ายเงินภายนอกไม่ได้ อาร์เทอร์ใช้ความรู้เรื่อง AWS VPC, NAT Gateway และ Security Group ที่เพิ่งอ่านสอบมา ชี้จุดผิดพลาดช่วยทีมสีเขียวของเอเลน่าได้ทันเวลา

บทที่ 12: กองทัพพอดไร้ระเบียบและวิชา Helm Chart — เมื่อโปรเจกต์ออสเตรเลียมีไมโครเซอร์วิสเพิ่มขึ้นเป็น 50 ตัว การก๊อปวางไฟล์ YAML แบบเดิมเริ่มจัดการไม่ไหว พี่กานต์จึงสอนอาร์เทอร์ให้รู้จักกับ Helm Chart เพื่อสร้างแม่พิมพ์ (Template) จัดการระบบร่วมกับ Argo CD

บทที่ 13: ท้าชนด่านอรหันต์ CKA (Kubernetes Cert) — เลียมเห็นแววของอาร์เทอร์ จึงมอบโควตาสอบฟรีของบริษัทให้สำหรับใบเซอร์สายลึกอย่าง CKA (Certified Kubernetes Administrator) ซึ่งไม่ใช่ข้อสอบกากบาท แต่เป็น "ข้อสอบปฏิบัติ (Hands-on Lab)" ที่ต้องพิมพ์คำสั่งแก้คลัสเตอร์ที่พังให้เสร็จภายใน 2 ชั่วโมง!

บทที่ 14: ฝึกวิชาพิมพ์ไวและการอัปเกรด AWS EKS — เพื่อเตรียมสอบ CKA และรับมือการอัปเกรดเวอร์ชัน AWS EKS ครั้งใหญ่ของซิดนีย์ อาร์เทอร์ฝึกใช้คีย์ลัด (kubectl alias) และการซ่อมแซมโหนดที่ตาย (Node Drain & Taint) โดยมีภพเป็นคู่ซ้อมจับเวลาให้ทุกพักเที่ยง

บทที่ 15: สองชั่วโมงตัดสินชะตาบนหน้าจอดำ — อาร์เทอร์เข้าสอบ CKA ออนไลน์จากที่บ้านในคืนวันอาทิตย์ โดยมีผู้คุมสอบฝรั่งเปิดกล้องจ้องดูทุกฝีก้าว อาร์เทอร์รัวคำสั่งแก้ปัญหา Network Policy และกู้คืนคลัสเตอร์จนหยดสุดท้าย และคว้าใบเซอร์ระดับยากของสาย Kubernetes มาครองได้สำเร็จ!

Arc 4: มหาศึก Black Friday และบทพิสูจน์มืออาชีพ (บทที่ 16 - 20)การนำทุกสกิลที่เรียนรู้มาตลอดทั้งเรื่อง มาหลอมรวมเพื่อรับมือกับวิกฤตที่ใหญ่ที่สุดของบริษัท

บทที่ 16: พายุที่กำลังก่อตัวและ Infrastructure as Code — ก่อนถึงเทศกาลช้อปปิ้งที่ใหญ่ที่สุดของออสเตรเลีย (Black Friday) พี่กานต์ต้องบินไปประชุมที่เมลเบิร์น ทิ้งให้อาร์เทอร์รักษาการดูแลทีม Blue ในไทย อาร์เทอร์ต้องเรียนรู้การใช้ Terraform เบื้องต้นเพื่อเตรียมขยายโครงสร้างพื้นฐานบน AWS รอรับคลื่นมหาชน

บทที่ 17: การโจมตีจากเงามืด (DDoS & WAF) — คืนเปิดแคมเปญ ทราฟฟิกพุ่ง 10 เท่าพร้อมกับมีบอทแฮกเกอร์ยิงถล่มเข้ามา อาร์เทอร์ต้องประสานงานเป็นภาษาอังกฤษแบบเรียลไทม์กับเอเลน่า (Green Team) เพื่อตั้งค่า AWS WAF / CDN สกัดกั้นบอทโดยไม่ให้กระทบลูกค้าจริง

บทที่ 18: วิกฤตซ้อนวิกฤตเมื่อ Data Center ล่ม — โซนเซิร์ฟเวอร์ (Availability Zone) แห่งหนึ่งในซิดนีย์เกิดไฟดับกะทันหัน พอดครึ่งหนึ่งหายไปจากระบบ! อาร์เทอร์ไม่ตื่นตระหนก เขาใช้วิชาจากใบเซอร์ AWS และ CKA สั่งย้ายทราฟฟิกและบังคับให้ Argo CD กระจายพอดไปยังโซนที่เหลือ (Multi-AZ Failover) ได้อย่างไร้รอยต่อ

บทที่ 19: เสียงปรบมือข้ามทวีป — แคมเปญ Black Friday จบลงด้วยยอดขายสูงสุดเป็นประวัติการณ์โดยที่ระบบไม่ล่มแม้แต่วินาทีเดียว (Zero Downtime) ในการประชุมรวมทั้งบริษัท (Town Hall) เลียมได้ประกาศชื่นชมอาร์เทอร์ต่อหน้าพนักงานทั่วโลก และอาร์เทอร์ได้พูดขอบคุณทีมงานเป็นภาษาอังกฤษอย่างมั่นใจ

บทที่ 20: Deploy ชีวิตใหม่ที่สมบูรณ์แบบ (บทสรุป) — วันประกาศผลประเมินครบ 3 เดือน อาร์เทอร์ไม่เพียงแต่ผ่านโปร แต่ได้รับการปรับตำแหน่งขึ้นเป็น Mid-level DevOps Engineer พร้อมฐานเงินเดือนใหม่ที่มั่นคง ด้วยผลงานหน้างานและใบเซอร์ระดับโลกทั้ง 2 ใบ เขากลับบ้านตรงเวลาในตอนห้าโมงครึ่ง พาลูกชายและภรรยาไปฉลองด้วยรอยยิ้มของหัวหน้าครอบครัวที่ก้าวข้ามขีดจำกัดของตัวเองได้อย่างสง่างาม
